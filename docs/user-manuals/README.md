## 所有角色通用

### 账户开通

- 投稿人在登录页自行注册，完成邮箱验证后登录；无需管理员邀请。
- 编辑、专家和管理员仍由管理员邀请，受邀人通过邮件链接填写姓名和至少 12 个
  字符的密码。邀请有有效期且只能使用一次。

本机测试入口是 `https://localhost`。2026-07-26 修复前发出的本地邀请可能错误指向
`http://localhost:5173`；这类旧邀请邮件应由管理员在“邀请记录”中重新发送。
本地证书由测试代理签发，浏览器首次打开时可能显示证书警告；确认地址确为
`https://localhost` 后，按浏览器提示允许本次本地访问即可。正式环境不得绕过证书
警告。

### 登录和找回密码

- 使用邮箱和密码登录。
- 忘记密码时选择“忘记密码”，输入邮箱并使用限时重置链接。
- 为防止他人探测账户是否存在，找回密码页面始终显示统一提示。
- 管理员要求强制重置后，旧密码、旧会话和全部接口密钥立即失效。

### 账户设置

右上角“账户设置”支持：

- 修改当前密码；
- 查看、创建和撤销接口密钥；
- 已启用双因素认证的账户重新生成恢复码。

普通网页操作依赖登录会话，不依赖接口密钥。接口密钥只用于脚本或获授权外部系统
调用，明文只显示一次，最长有效 90 天。

### 数据安全

- 不要通过聊天、普通网盘或未授权邮件转发未公开稿件、审稿意见和恢复码。
- 不要共享账户、密码、动态验证码或接口密钥。
- 发现账号异常、邀请并非本人申请或密码被修改，应立即联系管理员。
- 页面长时间无人使用后应退出登录；共用电脑不得保存密码。
