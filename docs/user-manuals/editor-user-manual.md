# 编辑用户手册

## 一、角色范围

编辑只能访问自己所属的编辑单元，可以上传或接收稿件、处理流程门禁、查看内部报告、
分配专家并提交预审和终审决定。编辑不能访问其他编辑单元稿件，也不能修改模型原始
评分。

系统给出的摘要、分档和决定建议只是辅助材料。正式决定必须由编辑独立判断并提交。

## 二、工作台结构

工作台左侧是可收缩导航，右侧是当前工作区。主要入口包括：

- 工作台：首页数量和最近投稿；
- 上传新稿件；
- 待处理稿件；
- 投稿列表；
- 通知中心。

页面顶部显示当前编辑单元及其“试运行”或“正式启用”状态。若没有编辑单元，应联系
管理员添加成员关系。

## 三、上传与查找稿件

### 上传

1. 选择“上传新稿件”。
2. 选择 PDF、DOCX 或 TXT。
3. 点击“上传并开始预审”。
4. 上传后进入投稿详情查看处理进度。

### 投稿列表

投稿列表显示题目、外部稿号、投稿时间、更新时间、流程状态和报告版本。可以按：

- 题目或外部稿号；
- 处理中、待人工处理、已完成、处理失败；
- 投稿日期起止；

进行筛选。已经评阅的稿件仍保留在列表中，可以再次打开历史报告和决定记录。

## 四、处理长任务和流程门禁

处理进度会显示当前阶段、当前六维、完成数/总数、百分比、最近心跳和失败摘要。

系统可能在以下环节暂停：

- 匿名化结果需要人工确认；
- 正文过短或章节结构异常；
- 未识别到参考文献、脚注或注释标记；
- 公共预检处于边界状态；
- 期刊适配性需要编辑判断。

暂停时应先阅读原始检查结论，再填写继续理由。继续操作只表示编辑确认稿件仍可进入
后续流程，不得覆盖原始检查结果。公共预检与期刊适配性是两套独立门禁，不能用期刊
偏好绕过公共准入问题。

系统先按确定性规则隐去邮箱、电话、元数据等身份字段，再由 GLM-5.2 检测身份高风险
段落并按原文片段精确替换。模型不能重写论文正文，也不参与本环节的学术评价。自动
处理成功后流程直接继续，并在通知中心和网页匿名稿顶部告知编辑处理模型及隐去数量；
编辑只需知悉并抽查。

只有模型不确定、返回片段无法精确匹配或调用失败时，流程才暂停人工确认。确认区会
直接显示在“稿件概览”的进度提示下。这里确认的是系统生成的网页匿名稿，而不是确认
原稿本来就符合匿名要求。仍有姓名、作者单位、邮箱、电话或其他身份线索时不要确认，
应从“新建投稿”上传已经人工匿名的版本。

## 五、阅读评阅报告

报告按以下顺序阅读：

1. 智能辅助综合摘要；
2. 五轴位置归属度；
3. 六维学术评价；
4. 专家复核意见；
5. 编辑决定历史。

### 智能辅助综合摘要

先核对综合判断、优点、主要问题、共识、分歧、优先核验项和修改建议。摘要由既有模型
评价与证据生成，不是人类审稿意见。

“发现两个观点差异维度”表示六个维度中有两个存在差异，不表示只运行了两个模型。
正常完整评价应显示四个匿名模型。

### 五轴位置归属度

五轴回答论文与中国自主知识体系的位置关系：

1. 对象归属度；
2. 材料归属度；
3. 范畴自主度；
4. 解释目标归属度；
5. 体系映射度。

首屏只显示五轴总分，需要核实时再展开逐轴分值范围和原文证据。五轴不评价论文质量，
不进入六维总分，也不直接决定录退。

### 六维学术评价

六维标准名称为：

1. 研究创新性；
2. 现状洞察度；
3. 理论建构力；
4. 逻辑连贯性；
5. 学术共识度；
6. 前瞻延展性。

逐维核对均分、标准差、优良中差、模型甲至模型丁的证据与理由。第二轮后任一维度
标准差大于 8，必须进入专家复核，不能通过增加模型轮次强行消除分歧。

核心—封顶—加分综合参考分只供参考：前四维形成基础，学术共识度设置上限，
前瞻延展性只作弱加分。

## 六、专家复核

1. 在“处理与决定”选择专家。
2. 点击分配复核。
3. 等待专家完成“独立评阅”和“对照复核”两个阶段。
4. 专家提交后，从报告查看独立判断、对照意见及与模型的冲突。

专家在独立阶段只看到匿名稿，不应看到模型结果。若发现隔离失效，应立即停止该任务并
报告管理员。

## 七、提交编辑决定

### 预审决定

- 不送外审；
- 修改后重投；
- 送外审；
- 优先送外审。

### 终审决定

只有已经进入外审流程的稿件才能提交终审决定：

- 退稿；
- 重大修改；
- 小修改后录用；
- 直接录用。

提交前检查决定阶段、决定类型和依据。决定提交后锁定，后续调整会生成新版本而不是
覆盖历史。偏离智能建议或绕过专家门禁时，必须写明理由；绕过专家门禁属于高风险审计
操作。

## 八、试运行与正式启用对编辑的影响

- 试运行：系统正常处理并保存全部结果，但智能建议默认作为受控测试材料，不直接形成
  编辑决定依据。
- 正式启用：该编辑单元已完成验证和签字，智能建议可按批准范围进入日常辅助流程。

状态由管理员按编辑单元切换。编辑应提供校准、冻结测试、最终验证和签字意见，不应
自行要求管理员跳过门禁。任何关键验证失败时，应建议退回试运行。

## 九、通知、报告与异常

- 通知中心显示预审就绪、处理失败、专家提交和任务转移等事件。
- 内部 PDF 应包含综合摘要、关键分歧、五轴、六维、专家复核、决定历史和方法边界。
- 页面少于四个模型、学术共识度缺失或专家提前看到模型结果，均视为阻断性问题。
- 任务停滞时先记录稿件编号、阶段、完成数和最近心跳，再交管理员处理；不要反复新建
  同一稿件。
