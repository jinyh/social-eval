# 投稿人用户手册

## 一、角色范围

投稿人可以上传本人获授权处理的论文、查看处理进度、阅读公开摘要和下载公开报告。
投稿人看不到模型真实名称、逐模型内部意见、编辑决定依据、其他投稿人的论文或专家
身份。

## 二、首次使用

1. 打开管理员发送的邀请邮件。
2. 点击“登录系统”，进入“激活账户”。
3. 填写姓名，设置并确认至少 12 个字符的密码。
4. 激活成功后返回登录页。
5. 使用邮箱和新密码登录。

如果邀请链接显示连接失败：

- 本机测试环境应使用 `https://localhost/activate#token=...`；
- 如果旧邮件指向 `http://localhost:5173`，请管理员重新发送邀请；
- 如果浏览器提示本地证书不受信任，确认地址确为 `https://localhost` 后允许本次
  本地访问；正式环境出现证书警告时不要继续；
- 不要把链接中的令牌发给他人，也不要自行删除 `#token=...` 部分。

## 三、上传论文

1. 进入“学生/投稿人入口”。
2. 在左侧上传区域选择文件。
3. 确认文件是 PDF、DOCX 或 UTF-8 编码的 TXT。
4. 点击“上传论文”。
5. 上传成功后，在“我的论文”选择该论文查看进度。

注意：

- 默认单个文件上限由部署配置决定，生产建议值为 30 MB。
- 扫描版 PDF 暂不提供文字识别。无法选择、复制正文的扫描件应先转换为可解析版本。
- 不要上传含无关个人信息、密钥或未获授权附件的文件。
- 文件扩展名与实际结构不符时系统会拒绝上传。

## 四、理解处理状态

| 页面状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 待处理 | 已收到文件，等待任务开始 | 稍后刷新 |
| 准入检查中 | 正在检查可解析性和基本结构 | 无需重复上传 |
| 准入未通过 | 文件或内容不满足基本处理条件 | 根据提示更换文件 |
| 评价中 | 多模型评价及交叉复核正在运行 | 保持等待 |
| 专家复核中 | 稿件已进入人工复核 | 等待复核完成 |
| 恢复中 | 系统正在重试部分失败处理单元 | 不要重复投稿 |
| 已完成 | 公开结果和报告已经生成 | 查看或下载报告 |
| 处理失败 | 当前任务无法自动恢复 | 联系编辑或管理员 |

处理页会显示百分比、已完成处理单元数、当前阶段和停滞提示。模型运行时间可能较长；
只要进度或最近心跳仍在更新，就不应重复上传。

## 五、查看公开结果

任务完成后，右侧显示公开摘要。公开结果用于帮助理解论文的学术特征和可改进方向，
不等于期刊录用或退稿决定。

投稿人公开页面不会展示：

- 模型真实名称；
- 模型甲至模型丁的完整内部意见；
- 编辑和专家的受控工作记录；
- 其他稿件信息。

点击下载报告可取得公开 PDF。若下载失败，先刷新页面；仍失败时记录论文编号和时间，
交给管理员排查，不要把论文正文再次发送到普通聊天工具。

## 六、删除论文

在“我的论文”中可删除不再需要的论文。页面会要求确认，删除操作不可撤销。对于正在
处理、已经形成编辑流程记录或期刊要求归档的稿件，应先联系编辑，不要自行删除。

## 七、密码和接口密钥

- 修改密码后，其他网页登录会话立即失效。
- 选择“同时撤销全部接口密钥”不会影响当前浏览器正常使用。
- 普通投稿人没有脚本接入需求时，不需要创建接口密钥。
- 忘记密码应走邮件重置，不要要求管理员查看旧密码；系统无法还原密码明文。

## 八、常见问题

- **一直没有报告**：查看当前阶段、完成数和停滞提示；超过系统提示时间再联系管理员。
- **系统说缺少参考文献、脚注或注释标记**：这属于形式完整性提示，不是学术否定；
  如稿件确有引注但未识别，应由编辑核对。
- **邮件已收到但链接无效**：邀请或重置令牌可能过期、已使用或已被重新发送；
  请管理员重新发送，旧链接会立即失效。
- **网页能登录但接口密钥失效**：网页会话与接口密钥相互独立，联系管理员确认是否
  被撤销。
