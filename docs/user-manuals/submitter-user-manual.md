# 投稿人用户手册

## 一、角色范围

投稿人可以自行注册账户、选择正式开放的期刊、提交本人获授权处理的论文、查看进度、
申请撤稿，以及在编辑发布后阅读公开摘要和下载公开报告。

投稿人看不到模型真实名称、逐模型内部意见、编辑内部决定依据、专家身份或其他人的
投稿。

## 二、注册和邮箱验证

1. 在登录页点击“投稿人注册”。
2. 填写姓名、电子邮箱和至少 12 个字符的密码；工作单位可以留空。
3. 点击“注册并发送验证邮件”。
4. 打开验证邮件并点击链接。验证链接 24 小时内有效且只能使用一次。
5. 页面提示验证成功后，使用邮箱和密码登录。

投稿人不需要管理员邀请。编辑、专家和管理员仍由系统邀请开通。

本机测试时，注册页可能显示“打开本地测试验证链接”；该链接仅用于开发环境。正式
环境不会在网页显示验证令牌。如果没有收到邮件，可再次提交注册或联系管理员检查
邮件投递；不要把验证链接发给他人。

## 三、选择期刊并投稿

1. 登录后进入“投稿人入口”。
2. 从列表选择一项正式启用的期刊或编辑单元。
3. 阅读页面展示的收稿范围、栏目定位、稿件类型和特别说明。
4. 填写论文题目。
5. 选择 PDF、DOCX 或 UTF-8 编码的 TXT 文件。
6. 点击“提交稿件”，保存系统返回的稿号。

注意：

- 系统不向投稿人开放仍处于试运行的期刊。
- 默认单个文件上限由部署配置决定，生产建议值为 30 MB。
- 扫描版 PDF 暂不提供文字识别，应上传可以选择和复制正文的版本。
- 投稿文件可包含作者信息；系统会生成匿名派生稿供模型和专家使用。
- 投稿人的账户姓名、邮箱和单位对编辑可见，但不会写入模型输入或专家匿名稿。

## 四、理解处理状态

| 页面状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 已收稿 | 系统已经收到文件 | 保存稿号并等待 |
| 稿件处理中 | 正在匿名化或解析文件 | 无需重复投稿 |
| 形式检查中 | 正在检查结构、篇幅和引注线索 | 等待处理 |
| 智能辅助评阅中 | 正在执行多模型评价和复核 | 等待处理 |
| 等待编辑处理 | 系统需要编辑确认门禁或作出决定 | 无需自行确认 |
| 专业复核中 | 稿件进入专家复核 | 等待编辑通知 |
| 处理完成 | 编辑流程已形成结果，但不代表已经向投稿人发布 | 等待发布 |
| 撤稿处理中 | 编辑正在处理撤稿申请 | 不要重复申请 |
| 已撤稿 | 编辑已经批准撤稿 | 稿号和审计记录继续保留 |

页面会显示百分比、已完成处理单元数、当前阶段和停滞提示。系统提示未识别到参考
文献、脚注或注释时，由编辑在内部流程核对，投稿人页面不提供门禁确认按钮。

## 五、查看公开结果

评价任务完成并不等于投稿人立即看到报告。编辑必须先提交并锁定决定，再点击
“发布给投稿人”。发布后，页面会显示：

- 编辑对外决定及作者可见说明；
- 投稿人公开摘要；
- 可下载的公开 PDF。

未发布前直接访问报告链接会提示“编辑尚未发布投稿处理结果”。公开结果不展示模型
身份、逐模型意见、内部分歧、专家身份或编辑内部理由，也不等于期刊最终录用。

## 六、申请撤稿

1. 打开对应投稿。
2. 点击“申请撤稿”。
3. 填写至少 5 个字符的原因并提交。
4. 等待责任编辑批准或驳回。

撤稿不是删除。批准后系统停止尚未开始的处理，不再向投稿人发布仍在执行的结果，
但会按留存规则保留稿号、版本、决定和审计记录。已有待处理申请时不能重复提交。

## 七、密码和接口密钥

- 修改密码后，其他网页登录会话立即失效。
- 普通投稿人只使用网页时不需要创建接口密钥。
- 忘记密码应使用登录页的邮件重置功能，管理员无法查看旧密码明文。
- 网页会话与接口密钥相互独立，撤销接口密钥不影响当前网页登录。

## 八、常见问题

- **无法登录**：先确认已经点击邮箱验证链接；未验证账户不能登录。
- **验证链接无效**：链接可能过期、已使用或已被新链接替换，请重新发送验证邮件。
- **列表没有期刊**：当前没有正式开放投稿的编辑单元，试运行单元不会显示。
- **一直没有公开报告**：查看进度；任务完成后仍需等待编辑发布。
- **需要修改已投稿文件**：当前版本不覆盖原稿，请联系编辑并按要求重新投稿。
- **误提交或需要撤回**：使用“申请撤稿”，不要要求管理员直接删除数据库记录。
