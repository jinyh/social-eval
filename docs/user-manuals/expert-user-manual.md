# 专家用户手册

## 一、角色范围

专家只能查看明确分配给本人的复核任务。系统向专家提供匿名稿，不展示作者身份、
原始文件名、未分配稿件或其他专家身份。

专家复核遵循“先独立、后对照”。独立意见一旦提交即锁定，之后才能看到四模型材料。
这一顺序用于防止模型意见影响专家的第一判断。

## 二、登录和任务列表

1. 使用邀请激活账户并登录。
2. 进入“专家复核工作台”。
3. 左侧“复核任务”显示任务、待复核维度数和当前阶段。
4. 选择一项任务后，在右侧网页直接阅读结构化匿名稿，无需下载 TXT 文件。

如果任务列表为空，可能尚未分配、任务已完成或账户不是指定专家。不要通过他人账户
查看，应联系责任编辑。

## 三、第一阶段：独立评阅

独立阶段右侧只显示匿名稿，页面不应出现模型分数、模型理由、综合参考分或模型证据。

操作步骤：

1. 通读匿名稿并核对需要复核的维度。
2. 对每个维度填写 0–100 分。
3. 填写能够独立成立的判断理由，说明文本证据、论证问题或认可依据。
4. 确认所有必填维度均已完成。
5. 点击“提交并锁定独立评阅”。

提交后不可覆盖。提交前不要把“稍后再改”当作保存草稿，也不要在理由中写作者身份
猜测或与评价无关的个人信息。

## 四、第二阶段：对照复核

独立评阅锁定后，系统开放“匿名稿”和“四模型对照”两个页签。

1. 在四模型对照中逐维阅读模型甲至模型丁的分数、证据和理由。
2. 对每项模型意见选择“认可”“不认可”或“无意见”。
3. 选择“不认可”时必须写明具体理由，例如引文断章取义、规范理解错误、遗漏关键
   反例或评分档位不当。
4. 需要核对正文时切回“匿名稿”，不要下载或另行传播原稿。
5. 填写必要的逐维补充说明。
6. 点击“提交并锁定对照复核”。

对照复核提交后，责任编辑可以查看专家的独立意见和对照结论。专家意见与智能结果
冲突时，系统保留冲突记录，不要求专家迁就模型。

## 五、六维判断提醒

六个维度为研究创新性、现状洞察度、理论建构力、逻辑连贯性、学术共识度和
前瞻延展性。

- 只评价被分配的维度，不擅自形成整篇录退决定。
- 区分“学术上不同意结论”和“论证不成立”；学术共识度不是要求观点保守。
- 理论型、制度型、判例型和比较法论文的理论建构表现不同，不能只用实务操作步骤
  衡量所有论文。
- 引用证据应能在匿名稿中定位，避免空泛评价。

## 六、保密和回避

- 发现可能认识作者、存在利益冲突或稿件未充分匿名时，停止评阅并联系编辑。
- 不复制、下载、转发或用于其他研究未公开稿件。
- 不把稿件提交给网页搜索、普通生成式人工智能工具或未授权连接器。
- 不在理由中披露其他审稿、会议或私人交流信息。

## 七、常见问题

- **独立阶段看不到模型结果**：这是预期设计，不是页面故障。
- **提交按钮不可用**：检查所有必填维度是否填写分数和理由。
- **提交后无法修改**：锁定是审计要求；确有重大错误时联系管理员，不要新建重复任务。
- **匿名稿无法加载**：记录任务编号和时间，停止评阅并联系管理员。
- **模型证据与正文不符**：选择“不认可”，写明可核对的位置和原因。
