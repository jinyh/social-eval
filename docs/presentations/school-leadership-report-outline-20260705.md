# 中国自主知识创新 AI 辅助评价体系建设汇报

面向学校主要领导的 PPT 内容稿  
建议副题：以法学论文评价试点为例，探索文科科研评价改革的新工具  
建议页数：11 页主汇报 + 1 页备用问答  
建议汇报时长：15 分钟左右  
汇报口径：争取领导认可、专家资源支持和后续跨学科试点空间

## 汇报主线

这份汇报不把重点放在“大模型技术展示”，而是回答校领导更关心的四个问题：

1. 学校为什么需要建设文科论文内容评价能力。
2. 这套体系和传统评价、专家评价是什么关系。
3. 法学试点已经验证了什么。
4. 下一步如何服务学校文科评价改革和自主知识体系建设。

建议全程强调三句话：

- AI 不替代专家，而是把专家从海量初筛和证据整理中解放出来。
- 评价不是简单排名，而是形成可复核的内容证据、候选发现和分歧记录。
- 法学试点的意义，是为学校文科评价改革提供可复制的方法样板。

## 02 背景问题：文科评价需要从外部标签回到内容证据

### 页面主结论

期刊、作者、机构、项目和引用等外部标签有管理便利性，但不能直接回答一篇论文是否真正形成知识贡献。

### 页面文字

**传统评价中的四个难点**

| 难点 | 具体表现 |
|---|---|
| 标准不一 | 不同专家、学科和场景口径差异较大 |
| 成本较高 | 高水平专家难以覆盖大规模论文初筛 |
| 周期较长 | 文科论文需要细读，难以快速形成结构化材料 |
| 标签替代内容 | 外部标签容易遮蔽真实问题意识和论证质量 |

**本项目切入点**

把评价重心从外部标签转向论文文本，识别问题意识、论证结构和可复核知识贡献。

### 建议图示

左右对比：

- 左：外部标签评价。
- 右：内容证据评价。

### 讲稿提示

这一页讲学校治理问题，不讲技术。听众需要先认同“为什么要做”，后面才会关心“怎么做”。

## 03 项目定位：AI 做辅助，专家做终审

### 页面主结论

系统定位是专家复核前的内容评价底稿生成工具，核心产出不是机器结论，而是证据、分歧和候选清单。

### 页面文字

**AI 负责**

- 大规模文本初筛。
- 评价理由和原文证据整理。
- 多模型分歧识别。
- 专家复核材料生成。

**专家负责**

- 判断最终学术价值。
- 判断学科意义和长期影响。
- 判断是否进入知识体系代表成果。
- 校准指标和典型案例。

### 建议图示

双栏图：AI 辅助能力 / 专家判断责任。中间用“复核材料”连接。

### 讲稿提示

这一页专门化解误解：不是让 AI 自动评价文科论文，而是让专家在更好的材料基础上做判断。

## 04 总体流程：先归属，再评价，再复核

### 页面主结论

评价流程先判断论文产出的知识是否进入自主知识体系位置结构，再评价其学术质量，最后把分歧和边界样本交给专家复核。

### 页面文字

**四阶段流程**

1. **项目口径预检**  
   判断论文是否适合进入内容评价流程。

2. **五轴知识归属判断**  
   判断论文产出的知识单元能否进入中国法学自主知识体系。

3. **六维内容质量评价**  
   判断论文的问题意识、理论建构和论证质量。

4. **专家复核触发**  
   将高价值、高分歧和边界样本形成复核清单。

### 建议图示

横向流程图：

论文文本 → 预检 → 五轴归属 → 六维评价 → 分歧识别 → 专家复核

### 讲稿提示

强调“先归属、再评价”的原因：自主知识体系建设首先要回答这篇论文生产的知识能否进入体系结构，然后才讨论质量高低和优先级。

## 05 第一层指标：五轴知识归属判断

### 页面主结论

五轴解决的是“这篇论文产出的知识能否放入中国自主知识体系”，不是直接判断论文质量高低。

### 页面文字

**五轴位置归属度**

| 轴 | 判断重点 |
|---|---|
| 对象归属度 | 是否处理中国制度、规范、司法或治理问题 |
| 材料归属度 | 是否使用中国语境中的材料和证据 |
| 范畴自主度 | 是否形成本土化概念、类型或判断标准 |
| 解释目标归属度 | 是否服务于解释中国问题 |
| 体系映射度 | 是否能映射到既有或候选知识体系节点 |

**汇报口径**

五轴不是“第七个质量分”，而是知识体系位置判断。

### 建议图示

中心放“知识归属”，周围五个轴环绕。不要和六维分数放在同一张雷达图里。

### 讲稿提示

这一页要把五轴讲清楚。对领导来说，最重要的是理解“这套体系不仅问论文好不好，还问它产出的知识应该放在哪里”。

## 06 第二层指标：六维内容质量评价

### 页面主结论

六维评价回答“论文作为学术成果质量如何”，重点看问题、现状、理论、逻辑、共识和延展。

### 页面文字

**六维内容评价**

| 维度 | 关注问题 |
|---|---|
| 研究创新性 | 是否提出清晰、可争辩、有推进价值的问题或命题 |
| 现状洞察度 | 是否准确把握既有研究和关键争点 |
| 理论建构力 | 是否形成可操作、可复用的分析框架 |
| 逻辑连贯性 | 材料、规范依据、论证与结论是否形成支撑链条 |
| 学术共识度 | 结论是否能被学术共同体定位、回应和检验 |
| 前瞻延展性 | 是否打开后续研究或制度讨论空间 |

### 建议图示

六维矩阵或六边形图，旁边加一句“用于内容质量评价，不替代专家终审”。

### 讲稿提示

这一页不讲复杂权重。领导只需理解：六维把文科论文评价拆成可解释的内容维度，避免只给一个黑箱分数。

## 07 可信机制：多模型评阅压缩偶然偏差，保留真实分歧

### 页面主结论

系统通过多模型独立评价和交叉复议降低单一模型偏好，同时把真实学术分歧保留下来交给专家判断。

### 页面文字

**机制设计**

- 多模型独立阅读，避免单一模型口径支配结果。
- 初评阶段相互隔离，保留原始判断。
- 复议阶段相互参照，压缩偶然偏差。
- 高分歧样本不直接删除，进入专家复核视野。

**稳定性结果**

| 指标 | Round 1 | Round 2 |
|---|---:|---:|
| 平均标准差 | 14.873 | 7.237 |
| 标准差 ≤ 8 的论文 | - | 1246 篇 |
| 标准差 > 12 的论文 | - | 101 篇 |

### 建议图示

两组点状分布：Round 1 分散，Round 2 收敛；右侧连接“专家复核”。

### 讲稿提示

这里讲可信度，不讲模型供应商。关键话术：收敛不等于机器正确，未收敛也不等于失败；未收敛往往正是专家需要看的地方。

## 备用页：领导可能追问的问题

### Q1：AI 会不会替代专家？

不会。AI 只负责初筛、证据整理和分歧提示，最终判断必须由专家完成。

### Q2：这个分数能不能直接用于排名？

不建议。相邻论文之间 0.1-0.3 分的差异不宜解释为实质高低，更适合用区间和候选池方式辅助专家阅读。

### Q3：为什么五轴要放在六维之前？

因为自主知识体系建设首先要判断论文产出的知识能否进入体系位置结构。五轴回答“放在哪里”，六维再回答“质量如何”。

### Q4：能否推广到其他文科？

可以，但不能简单复制法学指标。应保留“知识归属 + 内容质量 + 专家复核”的方法框架，再由各学科专家校准指标和知识库。

### Q5：学校现在最需要支持什么？

最需要专家复核闭环和跨学科试点场景。只有专家反馈进入系统，指标和模型才能从“可用”走向“可信、可推广”。
