### 新 P2 政策要求（合并旧 P2 + P3 + P4 → 1 页）
- 主结论：国家自 2020 年起明确要求破除唯论文、以内容质量为中心、推行代表性成果评价。
- 三文件时间线，每个只摘 1–2 关键句（删大段原文）：
  - 2020.10 中共中央、国务院《深化新时代教育评价改革总体方案》：破五唯；突出质量导向、推行代表性成果评价；分类评价、长周期、同行评议。
  - 2020.12 教育部《破除"唯论文"不良导向若干意见》：不得以刊评文、以刊代评、以人评文。
  - 2021.5 中共中央宣传部、教育部、科技部《推动学术期刊繁荣发展的意见》：**以内容质量评价为中心**（加粗，项目立论依据）。
- 图示：横向时间线 + 3 个文件卡片。
- 删：各文件大段原文摘录、底部角标"1"。

### 新 P3 现实困难（旧 P5 做强）
- 主结论：破除外部指标后，内容评价面临两大困难——这正是本项目要解决的。
