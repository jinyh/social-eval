# 中国自主知识创新指数构建研究报告

副题：基于 AI 辅助内容评价的法学论文初筛与专家复核框架  
报告类型：外部研究报告  
数据口径日期：2026-06-07

## 报告说明

本报告构建的是 AI 辅助的论文内容评价与专家复核候选发现机制。相关分数和清单用于识别值得进一步审阅的论文样本，不构成最终学术评价、期刊评价、学科评价或奖励推荐。

本报告面向法学与社会科学评价领域专家、项目主管单位及潜在合作机构。报告采用项目研究报告体例，重点说明指数构建思路、数据口径、评价流程、主要观察、可靠性检验和后续专家复核安排。公众传播版本另行压缩表达，不公开完整候选论文清单。

当前统计使用工作树中 2026-06-07 生成的可复现统计文件：

- `results/report_overview_stats.json`
- `results/report_group_stats.csv`
- `results/report_top_candidates_current.json`
- `results/report_id_integrity.json`
- `results/top101/top50-proportional.json`

全量样本为 1920 篇法学论文。元数据、统一评分结果和 Round2 评审结果的 PID 集合一致，编号范围为 1-1926，中间缺少 353、588、926、1019、1123、1584。所有表格均以 `results/merged-metadata.csv` 中的 `编号` 字段与评分结果中的 `pid` 对齐，不使用 CSV 行号或列表下标。

## 一、核心结论

第一，论文评价需要回到内容本身。本项目不把期刊层级、作者身份、机构声誉、项目头衔或引用量作为直接替代指标，而是围绕论文文本中的问题意识、研究现状、理论工具、论证链条、共同体可回应性和延展空间构建内容评价框架。这一路径可以作为破“五唯”的补充机制，但不能替代专家终审。

第二，多模型交叉评审能够显著降低初筛分歧。全量 1920 篇论文中，Round1 平均标准差为 14.873，Round2 降至 7.237，平均改善 7.636。论文层面，Round2 后平均 std ≤ 8 的论文有 1246 篇，≤ 12 的论文有 1819 篇；维度层面，8063 / 11520 个维度达到 std ≤ 8。这个结果说明 AI 辅助初筛具有可管理的稳定性，但仍需保留高分歧样本的专家复核。

第三，法学论文之间的差异主要集中在研究创新性、理论建构力和现状洞察度。六维统计显示，逻辑连贯性整体较高且更稳定，研究创新性平均分最低且分歧最高。这意味着专家复核不宜平均用力，应重点检查“问题是否真正推进学术共同体”和“理论工具是否可以被后续研究调用”。

第四，候选清单应理解为专家复核入口，而不是最终排名。当前 E2 候选池为 101 篇，按“内容评价分较高样本 + 年度覆盖 + 学科覆盖”形成；另按全量学科占比形成 50 篇专家审阅候选清单，用于有限专家时间下的集中讨论。候选论文可以公开供专家识别，但不宜以名次叙事呈现。

## 二、研究背景

传统科研评价容易把外部标签当成论文质量的近似变量。这些变量具有管理便利性，但它们并不直接回答论文是否提出了真正值得讨论的法学问题，是否形成了可复核的理论推进，是否对中国制度、规范和实践具有解释力。

中国自主知识体系研究尤其不能只依赖外部标签。许多论文不直接使用“自主知识体系”等显著表述，却可能在法教义学、制度解释、裁判规则或理论建构中处理中国问题。相反，部分论文即使使用显著标签，也未必形成可检验的法学命题。因此，本项目把评价重点放回论文文本：问题是否成立，研究现状是否把握清楚，理论工具是否可操作，论证是否连贯，结论能否进入共同体讨论，后续研究是否具有真实延展空间。

AI 在本项目中承担初筛、证据整理和一致性检验工作。它不替代专家终审，也不判断论文长期学术影响。更准确地说，AI 提供一份可复跑、可审计、保留分歧记录的内容评价底稿，再由专家判断哪些论文值得进入更细的复核和知识体系分析。

## 三、指数内涵与指标体系

本报告中的“自主知识创新”不等同于论文是否使用特定政治或学术标签。较稳妥的操作化定义是：论文是否从中国制度、规范、司法、治理或社会事实中提出问题，并将这些问题转化为可被法学共同体讨论的概念、命题、规则解释或制度判断。

这一判断包含三层含义：

第一，问题来源。论文处理的问题是否来自中国法治实践和制度运行，而不是把外部理论或域外制度作为不经转化的评价标准。

第二，理论转化。论文是否把材料、规范和既有研究组织成可复用的分析框架，而不只是描述现象或罗列政策背景。

第三，可复核性。论文提出的概念、类型、规则解释或制度建议，是否能够被其他研究者辨认、质疑、修正和继续使用。

### 3.1 六维内容评价指标

六维指标采用当前评价框架中的标准命名。权重设置遵循一个基本判断：自主知识创新潜力首先取决于问题和论证是否成立，其次才是传播便利性和外部延展。

| 维度 | 权重 | 评价含义 | 进入指数的理由 |
|---|---:|---|---|
| 研究创新性 | 0.30 | 是否提出清晰、可争辩、有推进价值的法学问题或命题 | 决定论文是否有真正知识增量 |
| 现状洞察度 | 0.20 | 是否说明既有研究到哪里、争点在哪里、本文从哪里切入 | 防止把已有观点重新包装为创新 |
| 理论建构力 | 0.15 | 是否形成可操作、可复用、能被后文调用的分析工具 | 判断论文能否成为知识体系节点 |
| 逻辑连贯性 | 0.20 | 框架、材料、规范依据和结论之间是否形成支撑链条 | 保证结论不是从立场或材料中跳出 |
| 学术共识度 | 0.10 | 结论是否能被学术共同体定位、回应和检验 | 控制过度个案化、过度断言和不可讨论结论 |
| 前瞻延展性 | 0.05 | 是否在现有论证基础上打开下一轮研究或制度讨论 | 作为弱加分，避免宏大展望替代已完成论证 |

六维主分按以下公式聚合：

```text
weighted_score =
  研究创新性 × 0.30
  + 现状洞察度 × 0.20
  + 理论建构力 × 0.15
  + 逻辑连贯性 × 0.20
  + 学术共识度 × 0.10
  + 前瞻延展性 × 0.05
```

这个分数的含义是“论文文本所呈现的学术质量和理论推进潜力”，不是最终奖励分、推荐分或专家结论。分数解释应以区间为主。全量样本中相邻论文往往只差 0.1-0.3 分，这类差异不宜解释为实质高低。

### 3.2 自主知识体系信号

自主知识体系信号单独记录，包括四项：中国问题中心性、中国实践解释尝试、外部理论转化动作、可复核概念或命题。每项 0-2 分，总分 0-8。

| 信号 | 判断重点 |
|---|---|
| 中国问题中心性 | 核心问题是否来自中国规范、制度、案例、治理或社会事实 |
| 中国实践解释尝试 | 是否解释中国实践中的结构性矛盾、制度逻辑或裁判分歧 |
| 外部理论转化动作 | 域外理论、比较法或一般理论是否经过转化，而不是直接套用 |
| 可复核概念或命题 | 是否提出可被辨认、引用、质疑和修正的概念、类型或判断标准 |

这 0-8 分不直接并入加权主分。学术质量和自主知识体系信号不是同一种量。高质量论文可能主要处理一般法理问题，自主信号较弱；低分论文也可能抓住了重要中国问题，但论证尚不充分。把两者硬加在一起，会掩盖专家真正需要判断的差异。

## 四、数据口径与评价流程

### 4.1 数据口径

本报告使用 1920 篇法学论文作为全量分析样本。数据来自论文元数据、统一评分结果和全量 Round2 评审结果。E2 候选池为 101 篇，选择规则为内容评价分较高样本、年度覆盖和学科覆盖组合。50 篇专家审阅候选清单按全量学科占比分配名额后，在各学科内根据内容评价结果和分歧情况形成，用于专家集中审阅和代表性样本核验。

需要区分两个“101”。一个是 E2 候选池 101 篇，另一个是 Round2 后平均 std > 12 的 101 篇高分歧论文。前者是候选池口径，后者是可靠性检验口径，二者不是同一集合。

### 4.2 评价流程

评价流程分为四步。

第一步是项目口径预检。预检只判断论文是否具备进入本项目六维评价的文内候选信号。文本工程问题另行记录，例如 OCR、脚注、排版和参考文献抽取风险，不把这些风险直接等同于项目口径边界。

第二步是六维评分。系统按同一套维度和权重读取论文文本，记录每个维度的分数、理由、证据和复核标记。全量阶段以 E1 结果为基础；进入候选池后，E2 复评对候选论文再次评分；部分内容评价分较高或分歧较高的论文进入 E3 选择性维度复评。

第三步是自主知识体系信号校验。系统识别论文是否真正围绕中国制度、规范、司法、治理或法学争论展开，是否把外部理论或比较法材料转化为服务中国问题的概念、判断标准或制度命题。

第四步是复核判断。复核分两层：预检层复核解决“是否进入评价流程”的门槛问题；评价层复核解决多模型分歧、高分弱证据、六维评分与自主信号矛盾等问题。复核报告优先呈现原文证据和分歧位置，而不是只给专家一个最终建议。

### 4.3 多模型与池化规则

本报告公开方法流程，不突出具体商业模型名称。全量阶段由多个主流大语言模型完成独立评分，并通过交叉评审压缩分歧。进入 E2 或 E3 后，同一维度累积到 8 个或 12 个模型分数时，使用中位数聚合，以降低极端模型分数对候选池分层的影响。

标准差不直接扣分。它用于判断结论可靠性和复核优先级。内容评价分较高但标准差较高的样本，不应直接删除，也不应直接采纳；更合适的处理是进入专家复核，把模型分歧作为专家判断材料。

## 六、候选池与专家审阅清单

### 6.1 E2 候选池

E2 候选池共 101 篇，选择规则为：先取内容评价分较高样本 60 篇，再按年度覆盖和学科覆盖补足，保证每个年份和每个当前学科分类都有最低观察样本。

101 篇候选池的复评分均值为 84.297，中位数为 85.875，最低为 61.400，最高为 89.225。候选池中 56 篇使用 E1+E2 聚合，45 篇使用 E1+E2+E3 聚合。其加权标准差均值为 5.513，中位数为 5.090，明显低于全量加权标准差均值 8.034。

这符合候选池的设计目标：它不是全量样本的随机子集，而是带有内容评价分层和覆盖补足的复评集合。候选池内部也应分层使用：内容评价分较高样本适合做重点审阅，年度和学科补足样本更适合做遗漏风险检查。

### 6.2 50篇专家审阅候选清单

50 篇专家审阅候选清单按全量 1920 篇论文的学科占比分配名额，再在各学科内部根据内容评价结果和分歧情况形成。这个口径服务于专家集中审阅和代表性分析，不用于替代 E2 101 篇候选池。

50 篇候选论文的分数范围为 82.60-89.22，均值为 86.799，中位数为 87.235。其可靠性整体较好：加权标准差均值为 4.858，中位数为 4.325；31 篇 std ≤ 5，47 篇 std ≤ 8，只有 3 篇 std > 8。

按学科名额看：

| 学科 | 名额 |

## 七、可靠性与边界

### 7.1 内部一致性

最直接的检验是多模型分歧是否收敛。全量 1920 篇中，Round1 平均 std 为 14.873，Round2 为 7.237。Round2 后，平均 std ≤ 8 的论文有 1246 篇，≤ 12 的论文有 1819 篇，仍有 101 篇 > 12。维度层面，8063 / 11520 个维度达到 std ≤ 8。

这个结果支持继续使用交叉评审机制，但也提示：剩余高分歧论文不能只靠模型自动裁断。内容评价分较高的论文中，若某个关键维度 std 偏高，应优先进入专家复核。

### 7.2 ID 完整性

当前 metadata、unified ranking、round2 三个集合完全一致，均为 1920 个 PID。E2 候选池和 50 篇专家审阅候选清单也都能在全量 ranking 中找到，没有缺失。这个检验很重要，因为项目中过去出现过 Paper ID 错位风险；本报告后续表格均以 `编号` / `pid` 连接。

### 7.3 尚未完成的外部检验

当前报告尚未接入教育部《手册》条目映射，因此不报告重叠率。后续应以 E2 101 篇和 50 篇专家审阅候选清单为对象，人工或半自动标注其与《手册》中的标识性概念、原创性理论和框架结构的对应关系。

当前报告也没有接入引用量和实质引用量数据，不使用替代数字。后续检验应至少区分三类情况：高内容分高引用、高内容分低引用、低内容分高引用。第三类尤其值得人工查看，因为高引用可能来自争议、综述性用途或教材性传播，不一定等同于自主知识创新。

## 八、局限性

第一，当前评价仍主要依赖文内证据。论文的长期影响、真实首创性、学术共同体接受情况，需要外部文献和专家知识补充。

第二，模型对不同学科的尺度并不完全一致。法学理论、党内法规学、数字法学等领域的低均值，可能同时包含论文质量差异、学科表达方式差异和模型评价偏好差异。

第三，前瞻延展性等弱加分维度仍可能波动。虽然它权重较低，但在头部论文分层中仍会影响细微差异。

第四，当前候选池已经做了年度和学科补足，但还没有完成与教育部《手册》、引用质量和专家标注之间的闭环检验。

第五，公开候选论文清单存在被外界误读为排名的风险。因此本报告附录只提供按学科分组的专家审阅候选论文清单，并使用分数区间和分歧区间，不给出名次。

## 九、后续工作

1. 固定 E2 101 篇作为复评候选池口径，并在后续报告中明确区分全量分布、E2 候选池和 50 篇专家审阅候选清单。
2. 以 50 篇专家审阅候选清单为基础组织专家审阅，并记录每篇论文的保留、调出和争议理由。
3. 补充教育部《手册》重叠检验，记录候选论文命中的标识性概念、原创性理论和框架结构。
4. 接入引用量和实质引用量，比较内容评价与传播评价之间的一致和偏离。
5. 对 Round2 后 std > 12 的 101 篇高分歧论文建立专家复核清单，优先处理内容评价分较高论文和 50 篇候选清单中的关键维度分歧。
6. 保留 ID 完整性检查作为每次报告生成的前置步骤，防止论文编号错位。
