## 数据口径说明

本报告使用当前工作树中的评审结果和元数据。全量指数口径为 1920 篇法学论文，数据来自 `results/merged-metadata.csv`、`results/unified_rankings.json` 与 `results/fullevaluation/round2/`。三者的 PID 集合一致，均为 1920 个；编号范围为 1-1926，中间缺少 353、588、926、1019、1123、1584。后续分析必须用 `编号` / `pid` 对齐，不使用 CSV 行号。

## 摘要

本项目尝试构建一种以论文内容为基础的中国自主知识创新指数。它不以作者身份、期刊名或引用量作为直接替代指标，而是围绕法学论文自身回答三个问题：是否提出了值得中国法学处理的问题，是否形成了能够解释中国制度和实践的论证结构，是否提出了可被学术共同体复核和继续讨论的概念、命题或判断标准。

当前全量样本为 1920 篇法学论文。全量加权分均值为 70.994，中位数为 74.487，P90 为 83.225，最高分为 88.525。按阈值看，分数达到 80 分及以上的论文有 460 篇，85 分及以上有 83 篇，88 分及以上有 3 篇，没有论文达到 90 分。这说明评价结果没有简单堆向满分区间，头部论文之间的分差也相对细。

多模型交叉评审显著降低了分歧。Round1 平均标准差为 14.873，Round2 降至 7.237，平均改善 7.636。维度层面，8063 / 11520 个维度达到 std ≤ 8，比例约 70.0%。这还不是“专家终审通过率”，但可以说明交叉评审机制能把模型间分歧压到可管理范围。

进入 E2 的候选池为 101 篇。该池不是单纯 Top 排名，而是 Top60、年度覆盖和学科覆盖的组合。101 篇的复评分均值为 84.297，中位数为 85.875，最高分为 89.225。候选池中 56 篇使用 E1+E2 聚合，45 篇使用 E1+E2+E3 聚合。另按全量学科比例生成专家审阅版 Top50，分数范围为 82.60-89.22，均值为 86.799。

## 一、研究背景：破“五唯”与内容评价的必要性

传统科研评价容易把期刊层级、作者身份、机构声誉、项目头衔和引用量当成论文质量的近似变量。这些变量有管理上的便利，但它们并不直接回答一个问题：论文到底提出了什么法学问题，是否形成了可复核的理论推进，是否对中国制度、规范和实践有解释力。

中国自主知识体系研究尤其不能只看外部标签。许多论文不直接使用“自主知识体系”这类表述，却可能在具体法教义学、制度解释或理论建构中处理中国问题。相反，部分论文即使使用了显著标签，也未必形成可检验的法学命题。因此，本项目把评价重点放回论文文本：问题是否成立，研究现状是否把握清楚，理论工具是否可操作，论证是否连贯，结论能否进入共同体讨论，后续研究是否有真实延展空间。

AI 在这里承担的是初筛和证据整理工作。它不替代专家终审，也不判断长期学术影响。更准确地说，AI 提供一份可复跑、可审计、带分歧记录的内容评价底稿，再由人工判断哪些论文值得进入更细的专家复核和知识体系分析。

## 二、自主知识创新指数的内涵与指标体系

本指数首先是内容评价指数，其次才是技术实现问题。对法学专家而言，它要处理的不是“模型认为哪篇论文好”，而是把论文质量中可以被复核的部分拆出来：问题意识、研究现状、理论工具、论证链条、共同体可接受性和延展空间。AI 只参与这些信号的初步识别和一致性检验，不改变指标本身的法学含义。

### 2.1 指数评价对象

“自主知识创新”在本报告中不等同于论文是否使用特定政治或学术标签。更稳妥的操作化定义是：论文是否从中国制度、规范、司法、治理或社会事实中提出问题，并将这些问题转化为可被法学共同体讨论的概念、命题、规则解释或制度判断。这个定义保留三层判断。

第一层是问题来源。论文处理的问题是否来自中国法治实践和制度运行，而不是把外部理论或域外制度作为不经转化的评价标准。

第二层是理论转化。论文是否把材料、规范和既有研究组织成可复用的分析框架，而不只是描述现象或罗列政策背景。

第三层是可复核性。论文提出的概念、类型、规则解释或制度建议，是否能够被其他研究者辨认、质疑、修正和继续使用。

### 2.2 六维指标

六维指标采用当前框架中的标准命名。权重设置遵循一个基本判断：一篇法学论文的自主知识创新潜力，首先取决于问题和论证是否成立，其次才是传播便利性和外部延展。

| 维度 | 权重 | 法学评价含义 | 进入指数的理由 |
|---|---:|---|---|
| 研究创新性 | 0.30 | 是否提出清晰、可争辩、有推进价值的法学问题或命题 | 决定论文是否有真正的知识增量 |
| 现状洞察度 | 0.20 | 是否说明既有研究到哪里、争点在哪里、本文从哪里切入 | 防止把已有观点重新包装为创新 |
| 理论建构力 | 0.15 | 是否形成可操作、可复用、能被后文调用的分析工具 | 判断论文能否转化为知识体系节点 |
| 逻辑连贯性 | 0.20 | 框架、材料、规范依据和结论之间是否形成支撑链条 | 保证结论不是从立场或材料中跳出 |
| 学术共识度 | 0.10 | 结论是否能被法学共同体定位、回应和检验 | 控制过度个案化、过度断言和不可讨论的结论 |
| 前瞻延展性 | 0.05 | 是否在现有论证基础上打开下一轮研究或制度讨论 | 只作为弱加分，避免以宏大展望替代已完成论证 |

这个权重结构有两个特点。其一，研究创新性、现状洞察度和逻辑连贯性合计 0.70，说明指数更重视论文已经完成的论证，而不是未来可能产生的影响。其二，理论建构力虽然权重为 0.15，但在头部论文判断中很关键；没有可复用的概念或分析工具，论文很难进入“知识体系”层面的讨论。

### 2.3 自主知识体系信号

自主知识体系信号单独记录，包括四项：中国问题中心性、中国实践解释尝试、外部理论转化动作、可复核概念或命题。每项 0-2 分，总分 0-8。

| 信号 | 判断重点 |
|---|---|
| 中国问题中心性 | 论文的核心问题是否来自中国规范、制度、案例、治理或社会事实 |
| 中国实践解释尝试 | 论文是否解释了中国实践中的结构性矛盾、制度逻辑或裁判分歧 |
| 外部理论转化动作 | 域外理论、比较法或一般理论是否经过转化，而不是直接套用 |
| 可复核概念或命题 | 是否提出可被辨认、引用、质疑和修正的概念、类型或判断标准 |

这 0-8 分不直接并入加权主分。原因很简单：学术质量和自主知识体系信号不是同一种量。高质量论文可能主要处理一般法理问题，自主信号较弱；低分论文也可能抓住了重要中国问题，但论证尚不充分。把两者硬加在一起，会掩盖专家真正需要判断的差异。

因此，本报告把自主信号用于分层和复核提示。高分且自主信号强的论文，是优先进入专家讨论的样本；高分但自主信号弱的论文，需要判断其是否只是一般学术质量高；低分但自主信号强的论文，则适合检查是否存在模型低估、学科表达差异或材料抽取问题。

## 三、自主知识创新指数构建方法

### 3.1 从论文文本到指数分

本项目的指数不是直接给论文贴“自主”或“不自主”标签，而是先把论文内容拆成若干可复核的评价信号，再汇总为可排序的主分。当前报告使用的指数主分是 `weighted_score`。为避免口径混乱，报告保留三类变量。

| 变量 | 用途 | 是否进入主分 |
|---|---|---|
| 六维学术质量分 | 形成论文内容质量的可排序主分 | 是 |
| 自主知识体系信号 | 判断论文是否围绕中国问题形成可复核命题 | 否 |
| 标准差与收敛指标 | 判断模型间分歧和专家复核优先级 | 否 |

这三类变量对应三种不同问题：论文质量如何，论文是否具有自主知识体系意义，当前机器辅助判断是否稳定。把它们分开，是为了让专家能够逐项校正，而不是面对一个无法拆解的总分。

六维主分按以下公式聚合：

```text
weighted_score =
  研究创新性 × 0.30
  + 现状洞察度 × 0.20
  + 理论建构力 × 0.15
  + 逻辑连贯性 × 0.20
  + 学术共识度 × 0.10
  + 前瞻延展性 × 0.05
```

这个分数的含义是“论文文本所呈现的学术质量和理论推进潜力”，不是最终的奖励分、推荐分或专家结论。自主知识体系信号、标准差、候选来源和专家意见不直接混入这个主分，而是作为解释、分层和复核变量保留。这样做有两个好处：一是避免把性质不同的东西混成一个黑箱分数；二是后续如果要调整候选规则，可以清楚知道改的是主分、可靠性阈值，还是学科/年度覆盖规则。

分数解释应以区间为主。全量样本中相邻名次往往只差 0.1-0.3 分，这类差异不宜解释为实质差距；80 分、85 分、88 分等阈值更适合用于分层观察。进入专家审阅阶段后，分数只提供排序线索，最终判断仍应回到论文原文和六维证据。

### 3.2 四阶段评价流程

评价流程分为四步。

第一步是项目口径预检。预检只判断论文是否具备进入本项目六维评价的文内候选信号。文本工程问题另行记录，例如 OCR、脚注、排版和参考文献抽取风险，不把这些风险直接等同于项目口径边界。

第二步是六维评分。系统按同一套维度和权重读取论文文本，记录每个维度的分数、理由、证据和复核标记。全量阶段以 E1 结果为基础；进入候选池后，E2 复评对候选论文再次评分；部分高分或高分歧论文进入 E3 选择性维度复评。

第三步是自主知识体系信号校验。系统识别论文是否真正围绕中国制度、规范、司法、治理或法学争论展开，是否把外部理论或比较法材料转化为服务中国问题的概念、判断标准或制度命题。

第四步是复核判断。复核分两层：预检层复核解决“是否进入评价流程”的门槛问题；评价层复核解决多模型分歧、高分弱证据、六维评分与自主信号矛盾等问题。复核报告优先呈现原文证据和分歧位置，而不是只给专家一个最终建议。

### 3.3 多轮评分与池化规则

全量阶段先形成 E1 结果，每篇论文由 4 个模型完成 Round1 和 Round2 交叉评审。这里的重点不是增加技术复杂度，而是让同一篇论文经历相互独立的判断，并把分歧留下来。进入候选池后，E2 对候选论文进行第二次复评；部分分数高或分歧大的论文再进入 E3 选择性维度复评。

聚合规则保持简单。只有 E1 的论文，用 4 个模型的均值。进入 E2 或 E3 后，同一维度累积到 8 个或 12 个模型分数时，用中位数聚合。中位数的作用是降低极端模型分数对候选池排序的影响。当前 Top101 中，56 篇为 E1+E2 聚合，45 篇为 E1+E2+E3 聚合。

标准差不直接扣分。它用于判断结论可靠性和复核优先级。一个高分但高标准差的样本，不应直接删除，也不应直接采纳；更合适的处理是进入专家复核，把模型分歧作为专家判断材料。

从机制上看，稳定性主要来自四个环节：同一维度多次独立评分、Round2 交叉评审、中位数池化、标准差阈值复核。这样的设计不会消除真实学术分歧，但可以把随机波动、单一模型偏好和极端分数对排序的影响降下来。

### 3.4 候选池生成逻辑

候选池采用“质量排序 + 覆盖约束”的规则。若只按全量分数取 Top60，候选质量最高，但年份和学科覆盖会偏窄。若完全按年份、学科平均分取样，又会牺牲头部质量。因此当前 E2 候选池按三条规则形成：

1. 先取全量加权分 Top60。
2. 再按年份覆盖补足，保证每年至少 5 篇。
3. 最后按学科覆盖补足，保证每学科至少 5 篇，得到 101 篇。

这个规则并不意味着补足论文与 Top60 的性质相同。Top60 更接近“分数驱动样本”，年度补足和学科补足更接近“覆盖驱动样本”。在专家审阅时，候选来源应和分数一起呈现。

Top50 专家审阅版采用另一套规则。它以 E2 候选池和复评结果为基础，按全量 1920 篇的学科占比分配 50 个名额，再在各学科内部按复评分择优。这个版本服务于专家集中审阅和代表性分析，不用于替代 E2 101 篇候选池。E2 解决“不要漏掉年度和学科样本”的问题；Top50 解决“有限专家时间下先看哪一批”的问题。

### 3.5 本报告的统计口径与解释边界

统计上，报告区分两个分数口径。全量 1920 篇使用 `results/unified_rankings.json` 的统一加权分。E2 候选池 101 篇使用 `results/top101/ranking.json` 的池化聚合分。前者用于观察总体分布，后者用于候选池和后续代表性论文讨论。

还需要区分两个“101”。一个是 E2 候选池 101 篇，另一个是 Round2 后平均 std > 12 的 101 篇高分歧论文。两者不是同一个集合。前者是候选池口径，后者是可靠性检验口径。

本报告不把全量均值差异直接解释为学科优劣或期刊优劣。学科主题、论文体裁、论证传统和模型尺度都会影响分数。报告中的学科、期刊和年度统计更适合作为专家审阅入口，用于发现结构性差异、抽查异常样本和设计后续验证，而不是直接形成评价结论。

## 四、主要结果

### 4.1 全量分布

全量 1920 篇的加权分均值为 70.994，中位数为 74.487。分布的几个关键位置如下：

| 指标 | 分数 |
|---|---:|
| 最小值 | 23.250 |
| P10 | 54.162 |
| P25 | 64.862 |
| 中位数 | 74.487 |
| P75 | 79.813 |
| P90 | 83.225 |
| P95 | 84.725 |
| P99 | 87.163 |
| 最大值 | 88.525 |

从阈值看，80 分及以上有 460 篇，85 分及以上有 83 篇，88 分及以上有 3 篇。90 分以上为空。这一分布比较适合初筛：它能形成头部候选，但没有把大量论文推到不可区分的高分区。

如果按比例看，80 分以上约占 24.0%，85 分以上约占 4.3%，88 分以上约占 0.2%。这说明 80 分可以作为较宽的高质量候选观察区，85 分更接近头部论文区，88 分以上已经是极小范围。后续若要控制专家工作量，可以把 80 分以上作为抽检底池，把 85 分以上作为重点审阅池，再叠加学科和年度补足。

从分布形态看，中位数高于均值约 3.5 分，说明低分长尾对均值有拉低作用。P25 为 64.862，P75 为 79.813，四分位距约 14.951 分。这个区间足以支持排序和分层，但不适合把相邻 0.2 或 0.3 分的论文解释为实质高低差异。头部论文排序应结合标准差、候选来源和专家复核，而不只看小数点后的名次。

### 4.2 可靠性分布

全量加权标准差均值为 7.974，中位数为 7.730。P75 为 9.980，P90 为 12.180，P95 为 13.580，最大值为 20.850。换言之，大部分论文的模型分歧在可讨论范围内，但仍有一部分样本存在明显判断差异。

Round2 对分歧的压缩比较明显：

| 指标 | Round1 平均 std | Round2 平均 std | 改善 |
|---|---:|---:|---:|
| 均值 | 14.873 | 7.237 | 7.636 |
| 中位数 | 14.770 | 6.925 | 7.530 |
| P90 | 19.300 | 10.800 | 10.470 |
| 最大值 | 27.520 | 17.170 | 15.080 |

按论文层面看，Round2 平均 std ≤ 5 的有 409 篇，≤ 8 的有 1246 篇，≤ 12 的有 1819 篇，> 12 的有 101 篇。按维度层面看，8063 / 11520 个维度达到 std ≤ 8。这个结果说明交叉评审不是形式环节；它确实降低了分歧，但没有把所有学术判断差异抹平。

### 4.3 六维表现

六维均值显示，逻辑连贯性和学术共识度整体较高，研究创新性和理论建构力更能拉开差异。

|---|---:|---:|---:|

这一结果符合项目预期。法学论文普遍能维持基本论证秩序，因此逻辑连贯性较高；真正困难的是问题是否有推进价值、理论工具是否能被后文持续调用。这也是后续专家复核应重点关注的部分。

六维里最不稳定的是研究创新性，平均 std 为 10.986；其次是理论建构力和现状洞察度，平均 std 分别为 8.720 和 8.576。比较稳定的是逻辑连贯性，平均 std 为 4.167。这一结构有解释力：模型比较容易判断一篇论文是否前后连贯，但对“问题是否真正推进学术共同体”和“理论工具是否足够原创、可复用”的判断更容易分歧。

这也提示后续专家复核的重点不应平均分配。创新性和理论建构力是指数中权重较高、分歧也较高的维度，最需要人工复核；逻辑连贯性可以更多作为基础质量过滤指标。

## 五、指数检验

### 5.1 内部一致性检验

最直接的检验是多模型分歧是否收敛。全量 1920 篇中，Round1 平均 std 为 14.873，Round2 为 7.237。Round2 后，平均 std ≤ 8 的论文有 1246 篇，≤ 12 的论文有 1819 篇，仍有 101 篇 > 12。维度层面，8063 / 11520 个维度达到 std ≤ 8。

这个结果支持继续使用交叉评审机制，但也提示：剩余高分歧论文不能只靠模型自动裁断。高分论文中若某个关键维度 std 偏高，应优先进入专家复核。

### 5.2 ID 完整性检验

当前 metadata、unified ranking、round2 三个集合完全一致，均为 1920 个 PID。Top101 候选池和 Top50 专家审阅清单也都能在全量 ranking 中找到，没有缺失。这个检验很重要，因为项目中过去出现过 Paper ID 错位风险；本报告后续表格均以 `编号` / `pid` 连接。

### 5.3 与教育部《手册》的重叠检验

当前报告尚未接入教育部《手册》条目映射，因此不报告重叠率。后续应以 E2 101 篇和按学科配额生成的 Top50 为对象，人工或半自动标注其与《手册》中的标识性概念、原创性理论和框架结构的对应关系。这个检验适合回答“模型选出的论文是否覆盖专家已归纳的知识体系节点”。

### 5.4 与引用量、实质引用量的比较

当前报告没有接入引用量和实质引用量数据，不使用替代数字。后续检验应至少区分三类情况：高内容分高引用、高内容分低引用、低内容分高引用。第三类尤其值得人工查看，因为高引用可能来自争议、综述性用途或教材性传播，不一定等同于自主知识创新。

### 5.5 专家检验

专家检验不应只看最终分数。更合适的材料包括：六维分数、原文证据、模型分歧、触发复核规则、自主知识体系信号和候选来源。建议至少抽查四类样本：E2 高分样本、学科补足样本、Top50 专家审阅版样本、Round2 后 std 仍 > 12 的高分歧样本。Top50 可作为集中审阅起点，E2 101 篇仍作为遗漏检查和学科观察底池保留。

## 六、评价系统特点总结

第一，评价对象从外部标签转向文本内容。系统不把期刊、作者或引用量作为直接分数，而是拆解论文内部的法学问题、研究现状、理论工具、论证链条和结论风险。

第二，评价过程可复跑。每篇论文保留模型分数、维度分歧、聚合方式和候选来源。即使后续专家不同意模型结论，也能追踪分歧发生在哪个维度。

第三，候选池不是单纯取高分。E2 的 101 篇同时考虑排名、年份覆盖和学科覆盖；Top50 再按全量学科比例形成专家审阅版。这一点对自主知识体系研究很关键，因为学科结构不平衡会影响头部名单。

第四，AI 只承担初筛、证据整理和一致性检验。系统设计本身保留专家复核，尤其针对高分弱信号、低分强信号、多模型分歧和特殊制度议题。

## 七、局限性

第一，当前评价仍主要依赖文内证据。论文的长期影响、真实首创性、学术共同体接受情况，需要外部文献和专家知识补充。

第二，模型对不同学科的尺度并不完全一致。法学理论、党内法规学、数字法学等领域的低均值，可能同时包含论文质量差异、学科表达方式差异和模型评价偏好差异。

第三，前瞻延展性等弱加分维度仍可能波动。虽然它权重较低，但在头部论文排序中仍会影响细微名次。

第四，当前候选池已经做了年度和学科补足，但还没有完成与教育部《手册》、引用质量和专家标注之间的闭环检验。
