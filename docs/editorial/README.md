## 已冻结边界

- 初始编辑单元：《交大法学》、《学术月刊》法学板块、《东方法学》。
- 管理员跨编辑单元管理；编辑仅访问其成员关系覆盖的编辑单元。
- 六维、R2、五轴和 CCB 沿用既有学术评价真源。期刊不得改写原始学术分。
- 期刊只配置适配性检查、优良中差到决定的映射和报告样式。
- 五轴独立展示，不进入决定；CCB 仅供参考，不作为决定阈值。
- 智能模型只给辅助建议。编辑的预审决定和终审决定分别提交、锁定并审计。
- 所有编辑单元先进入“试运行”；分别验证后才可转为“正式启用”。
- 未公开稿件在模型调用前默认匿名化；原稿与匿名稿分开保存。
- R2 后任一维度 `std > 8` 必须进入专家复核，不增加模型轮次仲裁。
- 编辑和专家看到四个匿名模型的实际分歧，不把四模型合并伪装成两份意见。
- 专家先阅读匿名稿并独立提交判断，锁定后才开放四模型结果。
- 五轴先显示总分，可展开五个轴的证据；五轴不评价论文质量。

## 当前实现阶段

实现按可验证纵切推进：

1. 组织、权限、投稿、匿名化和决定留痕；
2. 接入既有六维 R1/R2；
3. 接入五轴、四模型分歧与一份智能综合摘要；
4. 编辑工作台与管理员配置；
5. 本地验证、云端预发布和按编辑单元启用。
