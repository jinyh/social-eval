# 编辑辅助预审操作手册 v1.1

> 适用范围：法学稿件的编辑预审、专家复核和系统管理。
>
> 系统定位：提供辅助证据与风险提示，不替代编辑或专家作出决定。

## 1. 编辑完整测试流程

1. 使用编辑账户登录，选择所属编辑单元。
2. 上传可解析的 PDF、DOCX 或 TXT；扫描版 PDF 请先转换为可解析文本。
3. 查看原稿和匿名稿。匿名化存在不确定项时，核对后填写理由继续。
4. 查看形式完整性检查。正文过短、缺少章节结构或引注线索时，系统暂停；编辑确认
   稿件仍可评审后填写理由继续。
5. 分别查看公共预检和期刊适配性。两者是不同门禁，不得用期刊偏好覆盖公共准入问题。
6. 先查看智能辅助综合摘要，核对综合判断、优点、问题、共识、分歧、优先核验项和
   修改建议；该摘要不是人类审稿意见。
7. 等待四模型六维评价完成。确认页面显示“共四个模型”，逐维查看：
   - 均分、标准差和优良中差；
   - 模型甲至模型丁的分数、证据和分析；
   - 普通观点差异数量；
   - 标准差大于 8 的必须专家复核维度。
8. 查看核心—封顶—加分综合参考分。确认基础分、学术共识度封顶、前瞻延展性加分和
   最终值齐全。该结果只供参考。
9. 查看五轴位置归属总分。需要核对时展开五个轴的分数范围和证据。五轴不评价论文
   质量，也不参与录退决定。
10. 进入“处理与决定”；若需要专家复核，分配专家并等待专家完成两个阶段。
11. 提交预审决定：不送外审、修改后重投、送外审或优先送外审。
12. 收到外审材料后，再提交终审决定：退稿、重大修改、小修改后录用或直接录用。

## 2. 专家完整测试流程

1. 使用专家账户登录，打开分配给本人的任务。
2. 在“独立评阅”阶段直接阅读右侧结构化匿名稿。此时页面不应出现模型分数、
   模型意见、证据或综合参考分，也不应展示原始文件名。
3. 对指定维度填写 0–100 分和独立理由，提交并锁定。
4. 进入“对照复核”阶段，查看模型甲至模型丁的逐维分数、证据和判断；需要核对正文
   时，通过“匿名稿／四模型对照”页签返回匿名稿。
5. 对每项模型判断选择“认可”“不认可”或“无意见”。选择“不认可”时填写具体理由。
6. 提交并锁定对照复核。编辑端随后可查看独立判断和对照结果。

## 3. 管理员上线前检查

- 使用邀请制创建编辑和专家账户，并把编辑加入正确的编辑单元；
- 检查编辑只能访问其所属单元，专家只能访问明确分配的任务；
- 在试运行状态使用获授权测试稿完成上传、暂停继续、专家复核和两阶段决定；
- 确认报告中的模型名称对编辑和专家匿名，管理员审计界面仍可追溯实际模型；
- 确认 PDF 报告包含综合摘要、关键分歧、五轴、六维、专家复核、决定历史和方法边界，
  且页面脚注标注“仅供内部辅助研判”；
- 确认原稿、匿名稿、调用日志、专家记录和决定记录均可追溯；
- 完成数据库和稿件文件的异机备份及恢复演练；
- 验证通过并取得编辑签字后，按编辑单元转为正式启用。

## 4. 六维模型升级验证

生产模型集和候选模型集必须对同一批授权样本并行运行。候选任务使用独立记录，
不得覆盖生产任务。

建议按下列顺序执行：

1. 校准集：检查输出契约、失败率、维度偏移和新分歧；
2. 冻结测试集：确认问题修复没有破坏既有门禁；
3. 最终验证集：只在方案冻结后运行一次并形成签字记录。

每个阶段至少比较：逐维均值偏移、标准差变化、分档变化、专家复核触发变化、调用失败
率和编辑抽样意见。只有候选模型集通过批准，才能修改生产模型集指向；五轴配置保持
不变。回滚时恢复生产模型集指向，历史任务和候选任务均保留。

## 5. 常见异常

- 迁移容器失败：先查看迁移日志，确认数据库连接和当前迁移版本；不要跳过迁移直接启动。
- 上传后停在形式检查：核对是否为完整可解析论文；确认继续必须填写理由。
- 页面只显示少于四个模型：视为评价不完整，不应形成候选预审类别。
- 学术共识度缺失：视为六维结果不完整，同时检查综合参考分的封顶字段。
- 专家提交前能看到模型结果：属于流程隔离缺陷，应停止测试并修复。
- 五轴高分但公共预检认为边界：核对中国法材料和知识体系归属证据，不把五轴高分解释
  为论文质量高。
