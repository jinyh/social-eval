# 编辑辅助预审交互设计 v1.0

## 1. 信息架构

编辑登录后进入“投稿工作台”，由两栏组成：

- 左侧投稿列表：编辑单元、题目或外部稿号搜索、状态组、投稿日期、投稿时间、
  更新时间和报告版本；
- 右侧投稿详情分为“稿件概览”和“评阅报告”两个标签页。已生成报告的投稿默认打开
  “评阅报告”，处理中投稿默认打开“稿件概览”。

管理员使用独立后台，管理期刊、编辑单元、成员、模板版本和启用状态。

## 2. 编辑主流程

### 2.1 上传

编辑先选择编辑单元，再单篇或批量上传。可填写外部稿号。上传完成后立即展示系统稿号
和当前阶段；后台异步处理。

### 2.2 人工确认

遇到暂停节点时，详情页顶部显示阻断卡片：

- 匿名化不确定：显示命中的可识别信息类型，不默认展开原文；
- 公共预检失败：显示原始预检结论；
- 期刊适配性失败：显示独立的适配性理由。

操作只有“确认停止”和“填写理由后继续”。原始 AI 结果始终保留。

### 2.3 查看报告

报告标签页按以下顺序展示：

1. 五轴位置归属总分、五组标准说法、分数和可展开证据；
2. 核心—封顶—加分综合参考分的基础分、封顶、加分和最终值；
3. 四模型参与数量、共识、普通差异和必须专家复核的分歧；
4. 六维分档、均值、标准差及四模型证据；
5. 四模型综合摘要和候选预审类别；
6. 专家独立判断与四模型对照结果；
7. 调用与决定追溯。

五轴固定使用“轴名称—评价对象—判断问题”的三层说法，内容来自五轴框架配置；
六维名称与顺序来自该任务实际使用的六维框架配置。五轴与六维互不加总。

当建议被扣留时，不显示候选决定文字，改为明确的门禁原因。

### 2.4 专家复核

专家先查看匿名稿和空白评分表。独立评分及理由提交后不可覆盖，系统才显示四模型逐维
结果。专家随后对每项模型判断选择“认可”“不认可”或“无意见”；选择“不认可”时
必须填写对照理由。

### 2.5 编辑决定

编辑决定分为两阶段：

- 预审决定：不送外审、修改后重投、送外审、优先送外审；
- 终审决定：退稿、重大修改、小修改后录用、直接录用。

责任编辑正式提交时必须：

- 选择当前阶段允许的四档决定；
- 确认已阅读门禁和分歧；
- 若决定与智能候选类别不同，填写理由；
- 若绕过专家门禁，填写高风险理由。

提交后锁定，并显示版本、提交人和时间。管理员重开后生成新版本，不覆盖旧版。

## 3. 状态反馈

- 后台任务进行中时轮询状态，不重复提交；
- 失败显示失败阶段和可重试标记，不把供应商内部错误暴露给普通编辑；
- 完成、失败、专家提交和责任编辑转移产生站内通知；
- 邮件只包含系统稿号、事件类型和登录链接。

## 4. 空状态与权限

- 没有编辑单元成员关系的编辑看到明确的联系管理员提示；
- 没有投稿时展示上传入口和允许格式；
- 无权访问统一返回 404，降低跨编辑单元资源枚举风险；
- 管理员跨单元访问稿件时在页面持续显示“管理员审计访问”标识。

## 5. 响应式边界

桌面端优先。窄屏下列表和详情改为先列表、后详情的导航，不并排压缩学术报告。
