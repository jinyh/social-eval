# 四信号与五轴位置归属度评价综合报告

> 日期：2026-06-13  
> 面向对象：项目决策层  
> 报告目的：综合现有四信号与五轴评估结果，明确后续 1920 篇全量位置归属度评估路线。

---

## 1. 执行摘要

本报告建议将旧“四信号”降级为兼容字段、历史对照或轻量标签，不再作为“中国自主知识体系位置归属度”的主评分结构；将“五轴位置归属度评价”保留为正式主结构，并在 1920 篇全量评估中采用“全量五轴基线 + 条件仲裁 + ontology 扩展”的路线。

核心结论如下：

1. **四信号不适合作为位置归属度主分。**
  四信号主要测到“中国相关性”和若干低层特征，容易与预检重复，也容易与六维质量评价中的创新性、理论建构力发生交叉。其“可复核概念或命题”在 Top101 两模型评估中 200/200 次满分，已接近常量。
2. **五轴更适合作为位置归属度主结构，但不适合作为精排分数。**
  五轴在 Top101 高同质候选池中存在高分端饱和，满分率为 85/101（84.2%）。但它能提供四信号没有的结构信息，包括研究路径、范畴自主度、体系映射度、候选新增节点和专家复核线索。
3. **1920 篇不应再用六维分或四信号先筛。**
  六维评价已经完成，下一步应对 1920 篇建立独立的位置归属度画像。若先用六维分筛选，会漏掉“六维质量较低但知识体系归属强”的论文，破坏六维质量评价与五轴位置评价的解耦。
4. **第 5 轴应升级为 ontology 方法。**
  体系映射度不应理解为“是否命中某一本权威手册”，而应理解为“论文产出的知识单元能否进入可解释、可复核、可迭代的学科 ontology”。这使五轴比四信号更容易扩展到其他学科。

## 2. 评价对象与边界

四信号原结构包括：


| 信号       | 主要判断             |
| -------- | ---------------- |
| 中国问题中心性  | 是否围绕中国问题展开       |
| 中国实践解释尝试 | 是否解释中国实践或制度      |
| 外部理论转化动作 | 是否将外部理论转入中国语境    |
| 可复核概念或命题 | 是否形成可复核的概念、命题或判断 |


五轴结构包括：


| 轴       | 主要判断                           |
| ------- | ------------------------------ |
| 对象归属度   | 核心问题是否属于中国法秩序、制度、实践、争论或传统      |
| 材料归属度   | 核心材料是否来自中国规范、案例、制度、史料、实务或中文争论  |
| 范畴自主度   | 核心分析范畴是否经过中国法语境重置              |
| 解释目标归属度 | 最终解释目标是否指向中国法学知识生产             |
| 体系映射度   | 知识产出能否映射到既有节点、细化节点、交叉节点或候选新增节点 |


两套评价都不应替代六维质量评价。六维回答“论文质量如何”，五轴回答“论文产出的知识单元能否进入中国自主知识体系的位置结构”。位置归属度分不进入六维加权分，也不作为第七个质量维度。

### 2.1 预检、六维、研究路径与五轴的顺序

正式流程应固定为：

```text
论文输入
  ↓
预检：项目口径/边界/明显不适格
  ↓
进入正式评价池 / 边界池 / 不适格保留池
  ↓
并列独立评价：
  A. 研究路径分类 + 五轴位置归属评价
  B. 六维质量评价
  ↓
交叉分析：质量 × 归属 × 路径 × 预检状态
  ↓
专家复核 / Top50 或 Top100 候选 / ontology vNext 候选治理
```

四者关系如下：


| 环节   | 作用          | 输出                                                                        | 与其他环节关系                    |
| ---- | ----------- | ------------------------------------------------------------------------- | -------------------------- |
| 预检   | 判断项目口径与进入状态 | `enter_six_dimension_review` / `boundary_review` / `obviously_ineligible` | 只做路由，不提供质量分或位置分            |
| 研究路径 | 判断知识生产方式    | `research_route.primary/secondary`                                        | 分类画像，不计分，不决定五轴强弱           |
| 五轴   | 判断位置归属度     | 五轴 0-10、分歧轴、节点匹配、候选节点                                                     | 用于资格、画像、复核和 ontology，不进入六维 |
| 六维   | 判断学术质量      | 六维分与 `final_score`                                                        | 用于质量排序，不向五轴传递分数            |
| 交叉分析 | 合并解释结果      | 四象限、复核清单、榜单候选、ontology 候选                                                 | 后置分析，不新增评分维度               |


关键原则是：**预检在前，五轴/研究路径与六维在逻辑上并列独立，交叉分析和专家复核在后。** 即使工程执行上先跑了六维，五轴 prompt 也不应读取六维分数、排名或质量评语；预检状态只用于最终路由和候选资格，不应作为五轴高低分证据。

### 3.3 边界样本识别

五轴低于 8 分的 8 篇论文中，包含一般理论、比较法、法理方法、数字法学等边界类型。尤其有样本在四信号中得到满分，但五轴最终仅为 medium，并触发体系映射争议。这说明四信号容易把“中国相关 + 有明确命题 + 有外部理论转化”直接判为强信号，而五轴能进一步追问：

- 范畴是否真正经过中国语境重置；
- 论文产出的知识单元能否进入稳定知识节点；
- 体系映射是否只是宽泛学科归类；
- 是否需要专家确认候选新增节点。

这一增量对 Top101 精排帮助有限，但对专家复核、知识体系画像和 ontology 扩展具有实际价值。

## 4. 理论口径比较

### 4.1 四信号的定位

四信号适合作为历史兼容字段或项目相关性标签。它的优势是结构简单、成本低、解释门槛低；但作为位置归属度主分存在三个根本缺陷：

1. **与预检重复。**
  中国问题中心性和中国实践解释尝试容易退化为“是否属于项目口径”的判断。
2. **与六维质量评价交叉。**
  外部理论转化和可复核命题容易滑向创新性、理论建构力或论证质量判断。
3. **不能回答“归属到哪里”。**
  四信号能判断“有无中国相关信号”，但不能稳定给出研究路径、知识类型、既有节点、候选新增节点或体系映射争议。

因此，四信号不宜继续作为“中国自主知识体系位置归属度分”的主结构。

### 4.2 五轴的定位

五轴适合作为正式位置归属度评价结构。它把“是否中国相关”拆解为更可审计的五个问题：

- 核心对象在哪里；
- 核心材料来自哪里；
- 分析范畴是否经过本土语境重置；
- 解释目标是否指向中国知识生产；
- 产出的知识单元能否进入体系位置。

五轴不解决“论文好不好”，也不解决“论文创新强不强”。这些问题仍由六维质量评价处理。五轴解决的是“这篇论文产出的知识应如何放入中国自主知识体系”。

## 5. 五轴为何更易扩展到其他学科

五轴比四信号更适合跨学科扩展，原因不在于法学已有知识树，而在于五轴本身是学科中性的知识归属框架。

### 5.1 五个轴可抽象为跨学科通用问题


| 法学表达    | 跨学科抽象               | 其他学科示例                              |
| ------- | ------------------- | ----------------------------------- |
| 对象归属度   | 研究对象是否属于中国问题域       | 经济学中的中国经济现象；社会学中的中国社会结构；历史学中的中国历史经验 |
| 材料归属度   | 核心材料是否来自中国语境        | 中国数据、案例、档案、田野材料、政策文本、中文学术争论         |
| 范畴自主度   | 分析范畴是否经过中国语境重置      | 中国式现代化、基层治理、共同富裕、礼法传统、国家能力等概念重构     |
| 解释目标归属度 | 解释目标是否服务中国知识生产      | 解释中国制度运行、社会机制、历史路径或文化结构             |
| 体系映射度   | 知识产出能否进入学科 ontology | 既有节点、细化节点、交叉节点或候选新增节点               |


四信号中的“中国问题中心性”“中国实践解释”“外部理论转化”可以迁移到其他学科，但它们仍停留在相关性层面。五轴进一步要求材料、范畴、解释目标和体系位置之间形成结构化关系，因此更适合形成学科画像和知识谱系。

### 5.2 第 5 轴不依赖单一权威手册

体系映射度不应绑定某一本权威手册。更稳妥的设计是将第 5 轴定义为“知识位置可映射度”，并允许多种映射依据：


| 映射依据                | 适用场景                     | 处理方式                     |
| ------------------- | ------------------------ | ------------------------ |
| official_handbook   | 有权威手册、正式目录或成熟知识体系        | 优先匹配既有节点                 |
| expert_ontology     | 有专家构建的学科 ontology 或项目知识树 | 匹配既有节点，并提出细化或交叉节点        |
| discipline_taxonomy | 只有学科目录、教材体系、期刊栏目或关键词体系   | 先构建轻量 seed ontology      |
| candidate_node_only | 暂无成熟 ontology            | 允许提出候选新增节点，但降低置信度并触发专家确认 |


因此，没有权威手册不等于第 5 轴失效。手册只是高质量 seed ontology；没有手册时，可以从专家草案、教材章节、期刊栏目、关键词体系和全量论文中逐步构建 ontology。

### 5.3 评测与 ontology 构建可以形成闭环

五轴可以支持“边评测、边构建 ontology”的工作流：

1. **Seed ontology**：以现有知识树、学科目录、教材体系或专家草案为起点。
2. **单篇评测**：模型输出既有节点匹配、细化节点、交叉节点或候选新增节点。
3. **候选缓冲区**：候选节点记录父节点、节点类型、证据论文、模型一致性和专家状态。
4. **批量治理**：全量评测后做聚类、去重、合并同义项、拆分过宽节点、删除论文题目式节点。
5. **专家确认**：专家确认后升级为 ontology vNext。
6. **复评与更新**：下一轮评测使用更新后的 ontology，提高体系映射质量。

这一机制保证模型不是直接生成 ontology 真值，而是提供可审计候选；正式 ontology 仍由规则校验、聚类去重和专家确认共同决定。

### 5.4 泛化时需要保留的约束

跨学科扩展时必须保留三条约束：

1. **不得把位置归属度变成质量分。**
  不评价论文原创性强弱、论证是否成功、影响力高低。
2. **不得把候选节点直接写入正式 ontology。**
  候选节点必须经过去重、聚类、父节点校验和专家确认。
3. **不得把“研究中国问题”自动等同于强归属。**
  对象、材料、解释目标可以共享证据，但范畴自主度和体系映射度必须有独立证据。

## 6. 1920 篇全量评估建议

1920 篇六维评价已完成。后续位置归属度评估建议采用如下路线：


| 阶段                  | 目标                            | 方法                                                                     | 产物                              |
| ------------------- | ----------------------------- | ---------------------------------------------------------------------- | ------------------------------- |
| Stage 0：分层校准        | 校验五轴 prompt、证据门槛和 ontology 输出 | 约 120 篇分层样本；不把六维分输入模型                                                  | 校准报告、异常类型、抽检规则                  |
| Stage A：全量五轴基线      | 对 1920 篇形成统一位置归属画像            | deepseek-v4-pro + qwen3.6-plus，Round 1 + 条件 Round 2，逐轴保守聚合；预检状态只用于结果路由 | 路径分类、五轴分、分歧轴、节点匹配、候选新增节点        |
| Stage B：条件仲裁        | 提高关键样本可靠性                     | 对边界分、体系映射分歧、候选新增节点、Top50/Top100 候选引入第三模型或专家复核                          | 仲裁结果、专家复核清单                     |
| Stage C：ontology 治理 | 将评测结果转化为知识体系资产                | 聚类候选节点、去重、拆分、专家确认                                                      | ontology vNext 候选、节点覆盖报告、知识空白报告 |


1920 篇已完成的预检与六维结果用于后置 join，而不是作为五轴模型输入：

- `enter_six_dimension_review`：进入正式候选池，正常参与五轴画像和榜单资格判断；
- `boundary_review`：进入边界池，正常跑五轴，但最终候选需专家确认；
- `obviously_ineligible`：不进入正式候选排序；可保留为全库画像或 ontology 审计样本，但不得因五轴高分自动进入候选池；
- 六维 `final_score`：只用于质量排序和交叉展示，不用于推断五轴强弱；
- 研究路径：只用于知识生产方式分类，不计分，不作为五轴总分加权项。

第三模型不建议全量使用，应优先用于：

- 五轴总分 7-9，尤其影响 Top50 门槛的 8/9 分样本；
- `category_autonomy` 或 `system_mappability` 出现模型分歧；
- `candidate_nodes` 需要确认；
- 高六维低五轴、低六维高五轴；
- `weakly_related` 但六维质量高；
- Top50/Top100 拟入选论文。

旧四信号不建议作为 1920 的正式评分。若确需保留，可由五轴结果派生为 `legacy_autonomous_signals`：


| 旧字段      | 建议来源                            |
| -------- | ------------------------------- |
| 中国问题中心性  | `object_belonging`              |
| 中国实践解释尝试 | `explanatory_orientation`       |
| 外部理论转化动作 | `category_autonomy`             |
| 可复核概念或命题 | `system_mappability` 的节点证据与候选节点 |

### 6.1 工程落地入口

已按上述路线新增 1920 全量五轴评估入口：

```bash
# Stage 0：抽 120 篇分层校准样本
python scripts/evaluate_fullpaper_position_assessment.py \
  --stage0-sample-size 120 \
  --output-dir results/fullpaper-position-assessment-stage0

# 单篇 dry-run，用于检查模型、PDF 解析和输出契约
python scripts/evaluate_fullpaper_position_assessment.py --pid 1510 --limit 1

# Stage A：1920 篇全量五轴基线
python scripts/evaluate_fullpaper_position_assessment.py
```

脚本默认从 `results/merged-metadata.csv` 读取 1920 篇论文 ID，并从 `raw/fullpaper/` 匹配 PDF；不按六维分、四信号或 Top101 结果预筛。六维分与预检状态只在 `merged/` 结果中作为后置 join 字段输出，用于后续交叉分析，不进入五轴 prompt。

默认输出目录为 `results/fullpaper-position-assessment/`，包含：

- `round1/`：两模型 Round 1 五轴评估；
- `round2/`：按分歧条件触发的 Round 2 或 skip 标记；
- `merged/`：逐篇最终保守聚合结果，附带六维和预检后置上下文；
- `summary.json` 与 `report.md`：强度分布、路径分布、R2 分布、预检状态分布和复核数量。

## 7. 风险与治理要求

### 7.1 高分端饱和

五轴在 Top101 中满分率较高，说明它不适合做 Top101 内部精排。应将其用于资格过滤、画像展示、复核触发和 ontology 扩展，而不是替代六维质量排序。

### 7.2 范畴自主度误判

模型可能把中文术语或中国法条解释直接判为范畴自主。治理规则应明确：`category_autonomy=2` 必须说明核心范畴如何由中国制度、实践、传统、法学争论或语境转换生成。

### 7.3 体系映射度虚高

模型可能把宽泛学科标签当成明确节点。治理规则应明确：`system_mappability=2` 必须给出既有节点、细化节点、交叉节点或可命名候选新增节点；仅能归入宽泛学科时最多给 1 分。

### 7.4 ontology 膨胀

候选节点可能膨胀为论文标题库。候选节点进入正式 ontology 前必须满足：

- 可命名、可复述、可挂靠父节点；
- 不是论文题目的简单改写；
- 节点类型明确；
- 有原文证据；
- 有多篇论文支持，或经专家确认；
- 经过聚类、去重、合并和拆分。

### 7.5 模型一致性不足

两模型可用于全量基线，但关键边界样本仍需第三模型或专家仲裁。尤其是 `category_autonomy` 与 `system_mappability`，应作为优先复核轴。

---

## 8. 最终决策建议

1. **保留五轴作为正式位置归属度主结构。**
  五轴回答“论文产出的知识单元能否进入中国自主知识体系的位置结构”，比四信号更贴合项目目标。
2. **旧四信号降级。**
  四信号保留为历史对照、兼容字段或轻量标签，不再作为主评分结构，也不再用于替代五轴。
3. **Top101 / Top50 不用五轴精排。**
  Top101 内部仍以六维质量分排序；五轴用于资格池、画像、边界识别、复核触发和知识体系覆盖说明。
4. **1920 篇采用全量五轴。**
  不用六维阈值或四信号先筛，避免破坏质量评价与位置归属评价的独立性。
5. **第 5 轴采用 ontology 方法。**
  将体系映射度从“匹配既有手册”升级为“知识位置发现与候选节点治理”。这既能服务当前法学 1920 篇，也为未来扩展到其他学科提供通用框架。
6. **最终产物不应只有分数。**
  1920 篇全量五轴评估应同时产出路径分布、强度分布、分歧清单、节点覆盖、候选新增节点、ontology 空白区和专家复核清单。

---

## 9. 一句话结论

四信号适合作为历史兼容和相关性标签；五轴适合作为正式位置归属度评价主结构。下一步 1920 篇不应回退到四信号，也不应以六维分先筛，而应通过全量五轴评估建立知识体系位置画像，并以第 5 轴为入口同步推进 ontology 构建与跨学科泛化。
