## 5. 与 v0.2 方法论迭代闭环的衔接

v0.2 方法论文档 §9.1 设计的闭环流程：

```
种子本体（757 节点）→ 逐篇评估产出候选 → 候选缓冲区（当前阶段）→ 批量治理 → 本体 v2
```

当前状态：
- ✅ 种子本体已就位
- ✅ 逐篇评估已完成（1920 篇）
- ✅ 候选缓冲区已积累 5286 个候选
- ⬜ **批量治理尚未执行**——这是本体更新的下一步

### 候选缓冲区治理建议

1. **聚类去重**：5286 个候选中大量语义重复（如多篇论文提出"三权分置"相关候选），需聚类合并
2. **分层纳入**：P0 学科的细化节点优先纳入；P1/P2 待专家确认后纳入
3. **质量过滤**：排除 match_type 为空（495 个）和质量不达标的候选
4. **版本管理**：更新后的本体标记为 v2，与 v1（757 节点）并存，便于回溯对比

## 附录：数据提取方法

```bash
# 提取第5轴得分分布
for f in results/fullpaper-position-assessment-stage0/merged/paper-*.json; do
  jq -r '[.paper_id, .final.axis_scores.system_mappability.score,
          (.final.axis_scores.system_mappability.candidate_nodes // [] | length),
          (.final.axis_scores.system_mappability.node_matches // [] | length)] | @csv' "$f"
done > /tmp/axis5_all.csv

# 提取候选节点详情
for f in results/fullpaper-position-assessment-stage0/merged/paper-*.json; do
  jq -r '.final.axis_scores.system_mappability.candidate_nodes // [] | .[] |
         [.label, .match_type, .parent_node_id] | @csv' "$f"
done > /tmp/axis5_candidates.csv
```
