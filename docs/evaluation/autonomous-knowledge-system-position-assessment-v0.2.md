# 中国法学自主知识体系位置归属度评价方案 v0.2

> 状态：方法论草案  
> 日期：2026-06-12  
> 适用范围：法学论文评价中独立于六维学术质量评价的“中国法学自主知识体系”位置归属度判断  
> 版本说明：v0.2 在 v0.1 基础上明确“归属到哪里”、不再将新框架称为“信号”，并补充 0-1-2 量尺的理由、优缺点、防饱和规则与 ontology 迭代机制。

## 1. 问题边界

本方案只讨论“中国法学自主知识体系位置归属度评价”（下称“位置归属度评价”），不替代、不修正六维学术质量评价。

六维评价回答的是：

- 论文的研究创新性如何；
- 对研究现状的把握是否充分；
- 理论建构是否有力；
- 论证是否连贯；
- 结论是否能进入学术共同体讨论；
- 是否具有后续延展空间。

位置归属度评价回答的是：

- 论文处理的知识对象是否归属于中国法秩序、中国法实践、中国法学争论或中国法律传统；
- 论文的材料、范畴和解释目标是否服务于中国法学知识生产；
- 论文产出的知识能否被映射到中国法学自主知识体系的既有节点、细化节点、交叉节点或候选新增节点。

这里的“归属”不是指论文归属于“中国”、某种政治标签或某个宽泛主题，而是指论文所生产的知识单元能否被纳入中国法学自主知识体系的位置结构。位置结构至少包括：

1. 学科位置：如民法学、刑法学、行政法学、法理学、法律史学、国际法学等。
2. 知识类型位置：如标识性概念、原创性理论、框架结构、制度命题、解释规则、实践机制、传统资源转化等。
3. 具体节点位置：如既有知识树节点、细化节点、交叉节点，或有证据支持的候选新增节点。

因此，本方案不评价论文“好不好”“新不新”“论证是否成功”。这些问题已经由六维评价处理。

## 2. 基本原则

### 2.1 三不评

位置归属度评价不评：

1. 原创性强弱：交由“研究创新性”维度评价。
2. 论证质量：交由“逻辑连贯性”“理论建构力”等维度评价。
3. 学术影响潜力：交由六维综合分、引用分析和专家复核判断。

### 2.2 三个核心判断

位置归属度评价只评：

1. 知识对象是否属于中国法学语境。
2. 知识生产过程是否具有中国法语境归属。
3. 知识产出能否被放入中国法学自主知识体系的位置结构，并在必要时提出可复核的候选新增节点。

### 2.3 不与六维加总

位置归属度分不进入六维基础分，也不参与 `weighted_score` 计算。

它只用于：

- 候选论文分层；
- 专家复核优先级；
- 知识体系覆盖分析；
- 学科、年度、范式分布分析；
- 与知识树条目的匹配或候选新增节点识别。

### 2.4 与预检、六维和研究路径的流程关系

位置归属度评价应放在预检之后，并与六维质量评价保持逻辑独立。推荐流程为：

```text
预检
  ↓
进入正式评价池 / 边界池 / 不适格保留池
  ↓
并列独立评价：
  A. 六维质量评价
  B. 研究路径分类 + 五轴位置归属度评价
  ↓
交叉分析与专家复核
  ↓
榜单生成与 ontology vNext 候选治理
```

各环节边界如下：

| 环节 | 回答的问题 | 输出性质 | 约束 |
|------|------------|----------|------|
| 预检 | 是否属于项目评价范围 | 入口路由与边界复核 | 不给质量分，不给位置归属度分 |
| 六维 | 论文质量如何 | 质量分与 `final_score` | 不作为五轴评分依据 |
| 研究路径 | 通过何种知识生产方式进入体系 | 互斥主路径 + 可选副路径 | 不计分，不暗含强弱顺序 |
| 五轴 | 产出的知识单元是否具有体系位置归属 | 0-10 位置归属度、证据、节点 | 不进入六维加权分 |
| 交叉分析 | 如何解释质量、归属、路径和预检状态的组合 | 复核、候选、画像、ontology 治理 | 后置分析，不新增评分维度 |

因此，即使工程上已经先完成六维评价，五轴 prompt 也不应读取六维分数、六维评语或排名；预检结论只用于结果路由和候选资格，不应作为五轴高低分证据。

## 3. 当前四信号的问题

当前框架中的四项自主知识体系信号为：

- 中国问题中心性；
- 中国实践解释尝试；
- 外部理论转化动作；
- 可复核概念或命题。

这套设计适合作为项目口径或相关性标签。它们是低层特征，仍可称为 `signals`；但新方案是结构化评估框架，不应再称为“信号”。旧四信号不适合作为独立的位置归属度分，主要问题是：

1. 它与预检阶段高度重复。
2. 它容易测到“是否研究中国问题”，而不是“知识体系归属关系”。
3. 它与六维中的研究创新性、理论建构力存在潜在重叠。
4. 在 Top101 高分论文中区分度不足，容易出现大量满分或接近满分。
5. “可复核概念或命题”对高水平法学论文过于宽泛，容易成为常量。

因此，旧四信号后续应降级为兼容字段或项目口径标签，不再作为“中国法学自主知识体系位置归属度分”的主结构。

## 4. 推荐总体结构

新方案分为两步：

1. 研究路径分类：判断论文主要通过哪种知识生产路径定位到中国法学自主知识体系。
2. 五轴位置归属度评分：判断论文产出的知识单元与中国法学自主知识体系位置结构的关系强弱。

最终输出不叫 `autonomous_signal_score`，建议命名为：

```yaml
autonomous_knowledge_system_assessment
```

其中 `assessment` 表示结构化评估，不是单个信号读数。若需要保留旧字段，应命名为 `legacy_autonomous_signals`。

## 5. 研究路径分类

研究路径用于解释论文以何种方式进入中国法学自主知识体系。它不是质量分，也不暗含优劣顺序。

研究路径与五轴分数之间没有自动对应关系。`comparative_localization` 不天然低分，`chinese_doctrinal` 不天然高分；路径只描述知识生产方式，五轴只根据对象、材料、范畴、解释目标和体系映射的文内证据判定归属强弱。

### 5.1 主路径

`primary` 为互斥字段，取一个主路径：

```yaml
research_route:
  primary:
    - chinese_doctrinal
    - china_practice_governance
    - comparative_localization
    - chinese_legal_theory
    - traditional_resource_transform
    - interdisciplinary_china_data
    - weakly_related
  secondary: []
```

### 5.2 路径定义

| 路径 | 含义 |
|---|---|
| `chinese_doctrinal` | 围绕中国现行规范、制度、教义结构、司法解释或部门法体系展开 |
| `china_practice_governance` | 围绕中国司法实践、治理实践、监管实践或制度运行经验展开 |
| `comparative_localization` | 以比较法、域外制度或外部理论为资源，并将其置入中国法语境中转化 |
| `chinese_legal_theory` | 以中国法学理论、法理方法、法律概念或学术争论为中心展开 |
| `traditional_resource_transform` | 将传统法律文化、法律史资源或本土概念转化为现代法学问题 |
| `interdisciplinary_china_data` | 使用社会科学、数据、经验材料或跨学科方法解释中国法问题 |
| `weakly_related` | 与中国自主知识体系关系较弱，主要处理一般理论、域外制度或非中国语境问题 |

### 5.3 分类原则

- 路径分类只回答“属于哪类知识生产方式”，不回答“贡献是否优秀”。
- 一篇论文可以有多个路径，但必须指定一个主路径。
- 纯理论论文不应因缺少中国案例而自动降为弱相关；若其问题明确进入中国法学共同体争论，可归入 `chinese_legal_theory`。
- 比较法论文不因使用外部材料而自动低分；关键在于是否服务于中国法语境解释或制度转换。

## 6. 五轴位置归属度评分

五轴评分用于量化论文产出的知识单元与中国法学自主知识体系位置结构的归属关系。每轴 0-2 分，总分 0-10。满分 10 分表示五个归属侧面均有核心结构证据，不表示论文质量满分，也不表示论文创新性满分。

```yaml
axis_scores:
  object_belonging: 0-2
  material_belonging: 0-2
  category_autonomy: 0-2
  explanatory_orientation: 0-2
  system_mappability: 0-2
total_score: 0-10
```

统一评分规则：

| 分值 | 含义 |
|---|---|
| 0 | 无明确证据，或只是背景性提及 |
| 1 | 有局部证据，但不是论文核心结构 |
| 2 | 构成论文核心问题、核心材料、核心范畴、核心解释目标或明确体系位置 |

`uncertain` 不给 1 分。证据不足时应记为 0，并降低 `confidence`。

### 6.0 为什么使用 0-1-2 量尺

本方案使用 0-1-2，是因为位置归属度评价处理的是证据等级，而不是质量等级。

0-1-2 对应三种可审计状态：

1. `0`：没有明确证据，或只是背景性提及。
2. `1`：存在局部证据，但未进入论文核心结构。
3. `2`：构成论文核心结构，能在题目、摘要、问题提出、正文论证或结论中反复定位。

不使用 0-5 或 0-100 的原因是：更细的分值会诱导模型判断“做得多好、多深、多原创”，从而重新滑向六维评价中的研究创新性、理论建构力或逻辑连贯性。位置归属度评价应保持克制，只判断“是否构成中国法学自主知识体系的位置关系”。

0-1-2 的优点：

- 稳定：模型只需判断无证据、局部证据、核心证据三档。
- 可解释：每一分都必须对应原文证据或知识树位置。
- 不越界：避免把位置归属度误作论文质量或创新强度。
- 易聚合：适合多模型一致性统计、分层展示和专家复核。

0-1-2 的缺点：

- 区分度有限：同一强度档内不能做精细排序。
- 容易高分集中：中国制度教义学论文可能天然在对象、材料和解释目标三轴高分。
- `1` 档边界容易摇摆：模型可能在“局部证据”和“核心证据”之间不稳定。
- 等权加总仍有简化风险：五轴都给同等权重，可能掩盖不同研究路径的差异。

因此，本分数主要用于分层和画像，不应用于精确排序。`8` 与 `9` 的差异应解释为归属证据结构差异，而不是论文优劣差异。

### 6.1 对象归属度 `object_belonging`

判断论文处理的问题是否属于中国法秩序、中国制度、中国司法/治理实践、中国法学争论或中国法律传统。

得分锚点：

- 0：主要处理一般理论、域外制度或非中国语境问题，中国只作为背景或偶然例子。
- 1：涉及中国问题，但中国问题不是论文核心对象。
- 2：中国法问题、中国制度问题、中国实践问题或中国法学争论构成论文核心对象。

注意：不要求必须有中国案例。法理、方法论或法律史论文只要明确进入中国法学共同体问题，也可以得 2 分。

### 6.2 材料归属度 `material_belonging`

判断论文的核心材料是否来自中国规范、判例、政策制度、法律史料、实务材料、中文法学争论或中国经验数据。

得分锚点：

- 0：核心材料主要来自域外制度、外文理论或一般抽象论述。
- 1：中国材料存在，但主要作为说明、例证或背景。
- 2：中国规范、案例、制度、史料、实务或中文学术争论构成核心材料来源。

本轴不评价材料是否充分、是否使用得好；这些属于六维评价。

### 6.3 范畴自主度 `category_autonomy`

判断论文使用的核心分析范畴是否经过中国法语境重置。

得分锚点：

- 0：直接使用外部理论、域外概念或一般框架套用中国材料，未说明语境转换。
- 1：有一定转化或调适，但核心范畴仍主要依赖外部框架。
- 2：核心范畴由中国制度、实践、传统、法学争论或语境转换生成；或外部理论被明确改造成服务中国法问题的分析范畴。

本轴不评价该范畴是否原创或理论建构是否成功，只评价其语境归属。

### 6.4 解释目标归属度 `explanatory_orientation`

判断论文最终解释目标是否指向中国法学知识生产。

得分锚点：

- 0：中国材料主要用于验证一般理论，论文解释目标不在中国法问题本身。
- 1：论文部分解释中国法问题，但同时主要服务于一般理论或域外框架展示。
- 2：论文主要目标是解释、整理、重构或定位中国法制度、实践、理论或传统中的问题。

本轴不评价解释是否成功，只评价解释方向。

### 6.5 体系映射度 `system_mappability`

判断论文产出的知识能否被映射到中国法学自主知识体系的位置结构。

本轴的本体不是“是否命中某一本权威手册”，而是“论文产出的知识单元是否能够放入一个可解释、可复核的学科知识位置结构”。教育部相关手册、既有知识树或专家整理的 ontology 只是证据来源和映射参照，不是本轴的唯一依据。

为保证跨学科泛化，`system_mappability` 应区分映射依据：

```yaml
mapping_basis:
  - official_handbook        # 权威手册、正式知识体系或项目已确认知识树
  - expert_ontology          # 专家构建的学科 ontology 或种子知识树
  - discipline_taxonomy      # 学科目录、教材体系、期刊栏目、关键词体系等轻量分类
  - candidate_node_only      # 尚无成熟 ontology，只能提出候选新增节点
```

没有权威手册不等于本轴失效，也不应自动给 0 分。若论文能提出可命名、可复述、可挂靠父类的知识单元，可作为 `candidate_node_only` 或 `expert_ontology` 下的候选节点处理；但此类结果应降低 `confidence`，并优先进入专家确认。

得分锚点：

- 0：只能归入宽泛学科或主题，无法提炼出清晰知识单元、父节点或候选新增节点。
- 1：可映射到宽泛领域、问题域、方法域、既有节点、细化节点或交叉节点，但映射关系较粗或位置不稳定。
- 2：可明确映射到一个或多个既有节点，或可提出清楚的候选新增节点，且有原文证据、父节点、知识类型和命名理由支撑。

候选新增节点不代表论文更优秀，只代表其知识位置需要专家确认。

### 6.6 判分顺序与防饱和规则

为避免同一证据在五轴中机械重复计分，建议按以下顺序判分：

1. 先判对象归属度：论文核心问题是否属于中国法学语境。
2. 再判材料归属度：论文核心材料是否来自中国法规范、实践、史料、数据或中文学术争论。
3. 再判解释目标归属度：论文最终解释目标是否指向中国法学知识生产。
4. 再判范畴自主度：核心分析范畴是否经过中国法语境重置。
5. 最后判体系映射度：知识产出能否进入既有节点、细化节点、交叉节点或候选新增节点。

防饱和规则：

- 对象、材料、解释目标三轴可以共享部分证据，但不得因为“论文讨论中国法”而自动三轴全给 2。
- 常规中国法条解释可以在对象、材料、解释目标上得高分，但不能自动推出 `category_autonomy=2` 或 `system_mappability=2`。
- `category_autonomy=2` 必须说明核心范畴如何由中国制度、实践、传统、法学争论或语境转换生成；仅使用中文法学术语不足以得 2。
- `system_mappability=2` 必须给出明确的既有节点、细化节点、交叉节点或候选新增节点；仅能归入某个宽泛学科时最多得 1。
- 候选新增节点必须有可命名、可复述、可放入知识树的位置表达；不能把论文题目直接当作新增节点。
- 如果模型无法区分“归属关系强”与“论文质量高”，应降低 `confidence`，并触发复核。

## 7. 强度分档

```yaml
strength:
  strong: 8-10
  medium: 5-7
  weak: 2-4
  absent: 0-1
```

这里的 `strong` 只表示“与中国法学自主知识体系的位置归属关系强”，不表示论文质量高。

## 9. 与 ontology 构建的关系

体系映射度应优先复用当前 Top50 与中国法学自主知识体系树状知识库的匹配路线，但不应把知识树视为封闭答案库。更合理的定位是：以现有知识树作为 seed ontology，在五轴评测过程中同时发现候选节点、候选关系和知识空白，形成“边评测、边扩展 ontology”的闭环。

知识树或 ontology 匹配可以提供：

- 既有节点匹配；
- 学科归属；
- 标识性概念、原创性理论、框架结构的候选对应；
- 候选新增节点提示。

但 ontology 匹配不能替代五轴评分，因为：

- 知识树可能不完整；
- 没有匹配不等于没有体系意义；
- 高匹配数量不等于高质量或高自主性；
- 一篇论文可能对应一个很窄但很重要的候选新增节点。

因此，ontology 匹配应作为 `system_mappability` 的证据来源，而不是独立决定总分。

### 9.1 Ontology 迭代闭环

建议将五轴评测与 ontology 构建拆成四层：

1. **Seed ontology**：法学可使用现有“中国法学自主知识体系树状知识库”；其他学科可先使用学科目录、教材章节、核心期刊栏目、关键词体系或专家草案。
2. **单篇评测**：模型只能提出既有节点匹配、细化节点、交叉节点或候选新增节点，并必须附原文证据、父节点、知识类型和命名理由。
3. **候选缓冲区**：新节点先进入 `candidate_nodes`，不得直接写入正式 ontology。候选节点应记录 `label`、`parent_node_id`、`node_type`、`evidence_quotes`、`supporting_paper_ids`、`model_agreement`、`expert_status`。
4. **批量治理**：跑完全量后再做聚类、去重、合并同义项、拆分过宽节点、删除论文题目式节点，并由专家确认后升级为 ontology vNext。

候选节点进入正式 ontology 的建议条件：

- 至少多篇论文提供独立证据，或单篇高价值论文经专家确认；
- 能挂靠到稳定父节点；
- 不是论文标题改写，而是可复用知识单元；
- 至少两模型一致，或经第三模型/专家仲裁确认；
- 节点类型明确，如 `concept`、`theory`、`framework`、`doctrine`、`mechanism`、`method`、`case_pattern`。

这个机制保证模型不是直接生成 ontology 真值，而是提供可审计候选；正式 ontology 仍由规则校验、聚类去重和专家确认共同决定。

## 10. 与六维评价的交叉展示

位置归属度分与六维学术质量分只做交叉展示，不做加总。

| 六维质量分 | 位置归属度分 | 解释 |
|---|---|---|
| 高 | 高 | 高质量且与中国法学自主知识体系位置归属关系强，适合优先专家审阅 |
| 高 | 低 | 高质量一般法学研究，不因位置归属度分低而否定 |
| 低 | 高 | 议题、材料或体系归属强，但论文质量问题由六维解释 |
| 低 | 低 | 当前项目优先级较低 |

这一区分可以避免把“位置归属度评价”变成对论文质量的重复打分。

### 10.1 Top50 选择规则

当 Top50 的目标是形成“中国法学自主知识创新代表论文”清单时，采用“归属先行、学科配额、质量排序”的规则：

1. 先以五轴位置归属度总分 10 分论文作为主资格池。
2. 再按 1920 篇全库学科比例确定 Top50 学科配额。
3. 在每个学科配额内部，按六维创新评价加权分排序择优。
4. 若某学科 10 分论文不足以填满配额，仅允许从同学科五轴位置归属度 9 分论文中择优补足。
5. 五轴位置归属度 8 分及以下的论文原则上不进入 Top50，只保留为高质量一般法学论文、观察样本或专家复核样本。
6. 位置归属度只决定主榜候选资格、配额补足和知识体系画像，不进入六维加权分，也不作为第七个质量维度。

该规则适用于 Top101 已完成位置归属度评估后的 Top50 主榜选择；当前 canonical 产物为 `results/top101/top50-position-first-proportional.json`、`.csv` 和 `.md`。如需生成展示版或专家审阅版清单，可在上述规则基础上另行标注年度、分歧复核状态和专家调整理由。

## 11. 复核触发建议

复核触发应围绕“体系归属判断是否可靠”，而不是围绕六维分数高低。

建议触发规则：

```yaml
review_triggers:
  - high_aks_score_but_weak_evidence
  - candidate_new_node_requires_expert_confirmation
  - model_disagreement_on_category_autonomy
  - model_disagreement_on_system_mappability
  - external_framework_dominant_disagreement
  - weakly_related_but_high_quality_general_legal_theory
```

说明：

- 不再使用“高六维分但中国信号弱”作为自动复核理由。
- 高质量但位置归属度分低的论文可作为一般法学高质量样本保留，不应被系统性惩罚。
- 候选新增节点应优先进入专家确认，因为这关系到知识树扩展，而不是论文质量排序。

## 12. 旧四信号迁移关系

旧四信号可迁移为新五轴的部分证据，但不再直接加总。

| 旧信号 | 新位置 |
|---|---|
| 中国问题中心性 | 对象归属度 |
| 中国实践解释尝试 | 解释目标归属度 |
| 外部理论转化动作 | 范畴自主度 |
| 可复核概念或命题 | 体系映射度的辅助证据 |

旧字段可保留为 `legacy_autonomous_signals`，用于历史结果兼容。

## 13. 建议验证方式

在进入配置实现前，建议先做小样本验证。

### 13.1 验证样本

建议选取：

- Top50 中高六维分、高知识树匹配论文；
- 高六维分但当前自主信号较低论文；
- 纯理论/法理方法论文；
- 比较法本土化论文；
- 法律史或传统资源转化论文；
- 中国制度教义学论文。

### 13.2 验收指标

重点看：

- 五轴分布是否比旧 0-8 信号更有区分度；
- 是否减少与六维创新性、理论建构力的重复；
- 模型在 `category_autonomy` 和 `system_mappability` 上的分歧是否可解释；
- 专家是否能根据输出证据判断分数是否合理；
- `candidate_nodes` 是否能为知识树扩展提供有效线索。
