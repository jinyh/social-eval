# Pattern 重新设计分析

## 目标

从专家意见中提取**可机械化检查**的特征，避免依赖"论证质量判断"。

## 专家意见分析

### 可机械化的特征（✅ 推荐）

| 专家意见 | 可观察指标 | 检测方法 |
|---------|-----------|---------|
| **邵莉莉**："空谈义务、权利、责任" | 规范性表述（"应当""必须""需要"）的数量 vs 具体法条引用数量 | 统计"应当/必须/需要"出现次数，统计法条引用（如"第X条""XX法"）次数，计算比例 |
| **杨清望**："从立法、司法、执法、守法四个方面开展论述，完全是生搬硬套" | 使用固定四分法框架 + 每个分类下的字数 | 检测是否出现"立法-司法-执法-守法"或"制度-机制-保障"等固定框架，统计每个分类下的字数 |
| **伍德志**："主要篇幅用于介绍...对于...的论述太过简略，头重脚轻" | 不同部分的篇幅比例 | 识别"现象描述/概念介绍"部分和"法律分析/制度构建"部分，计算字数比例 |
| **崔聪聪**："大量使用...等概念进行堆砌，并未对这些概念作出详细解释" | 学术概念数量 vs 概念解释数量 | 识别学术概念（引号内的术语、专有名词），检查每个概念后是否有"是指""即""定义为"等解释性表述 |

### 不可机械化的特征（❌ 避免）

| 专家意见 | 为什么不可机械化 |
|---------|-----------------|
| "并未真正的完成将爱国主义从一种道德观念到法律概念上的转变" | 需要理解论证逻辑和概念转化过程 |
| "不足以支撑形成成熟的权利义务配置方案" | 需要判断论证的充分性和方案的成熟度 |
| "建议多停留在方向性层面，不够具体可落实" | 需要判断建议的可操作性（主观） |
| "无法得到充分的证明" | 需要判断论证的充分性（主观） |

## 重新设计的 Pattern

### Pattern 1: `normative_statement_without_specifics`（规范性表述缺少具体支撑）

**目标案例**: 邵莉莉

**可观察指标**:
- 规范性表述数量：统计"应当""必须""需要""亟需""应该"等词的出现次数
- 具体支撑数量：统计法条引用（"第X条""XX法""XX条例"）、具体制度名称、程序步骤描述

**检测逻辑**:
```
IF 规范性表述数量 >= 10 AND 具体支撑数量 / 规范性表述数量 < 0.3:
    触发 pattern
```

**Prompt 设计**:
```
请统计论文中以下两类内容的数量：

1. 规范性表述：包含"应当""必须""需要""亟需""应该"等词的句子数量
2. 具体支撑：包含以下任一内容的句子数量
   - 法条引用（如"第X条""XX法""XX条例"）
   - 具体制度名称（如"XX登记制度""XX审查程序"）
   - 程序步骤描述（如"首先...其次...最后"）

输出格式：
{
  "normative_statements": 数量,
  "specific_supports": 数量,
  "ratio": 具体支撑数量 / 规范性表述数量,
  "triggered": ratio < 0.3 AND normative_statements >= 10,
  "evidence_quotes": ["规范性表述示例1", "规范性表述示例2"]
}
```

### Pattern 2: `fixed_framework_mechanical_application`（机械套用固定框架）

**目标案例**: 杨清望

**可观察指标**:
- 是否使用固定框架：检测"立法-司法-执法-守法"或"制度-机制-保障"等固定分类
- 每个分类下的字数：统计每个分类标题后到下一个标题之间的字数

**检测逻辑**:
```
IF 使用固定框架 AND 平均每个分类字数 < 200:
    触发 pattern
```

**Prompt 设计**:
```
请检查论文结论/建议部分是否使用了以下固定框架：
- "立法-司法-执法-守法"四分法
- "制度-机制-保障"三分法
- 其他类似的固定分类框架

如果使用了固定框架，请：
1. 识别框架类型
2. 统计每个分类下的字数（从分类标题到下一个标题）
3. 判断是否每个分类下都有实质内容（字数 >= 200）

输出格式：
{
  "uses_fixed_framework": true/false,
  "framework_type": "立法-司法-执法-守法" 或 null,
  "categories": [
    {"name": "立法", "word_count": 数量},
    {"name": "司法", "word_count": 数量}
  ],
  "avg_word_count": 平均字数,
  "triggered": uses_fixed_framework AND avg_word_count < 200,
  "evidence_quotes": ["框架使用证据"]
}
```

### Pattern 3: `concept_stacking_without_explanation`（概念堆砌无解释）

**目标案例**: 崔聪聪

**可观察指标**:
- 学术概念数量：识别引号内的术语、专有名词（如"监管合作主义""穿透式监管"）
- 概念解释数量：检查每个概念后是否有"是指""即""定义为""指的是"等解释性表述

**检测逻辑**:
```
IF 学术概念数量 >= 5 AND 有解释的概念数量 / 学术概念数量 < 0.4:
    触发 pattern
```

**Prompt 设计**:
```
请识别论文中的学术概念（通常用引号标注或为专有名词），并检查每个概念是否有解释：

1. 学术概念：引号内的术语、专有理论名称、学说名称
2. 概念解释：概念后紧跟"是指""即""定义为""指的是"等解释性表述

输出格式：
{
  "concepts": [
    {"name": "监管合作主义", "has_explanation": true/false, "explanation": "解释内容或null"}
  ],
  "total_concepts": 数量,
  "explained_concepts": 数量,
  "explanation_ratio": 有解释的概念数量 / 总概念数量,
  "triggered": total_concepts >= 5 AND explanation_ratio < 0.4,
  "evidence_quotes": ["概念堆砌示例"]
}
```

## 小规模验证计划

### 验证样本（5 篇）

**负样本（3 篇）**:
1. 邵莉莉 — 预期触发 Pattern 1
2. 杨清望 — 预期触发 Pattern 2
3. 崔聪聪 — 预期触发 Pattern 3

**正样本（2 篇）**:
1. 蒋红珍（比例原则位阶秩序的司法适用）
2. 杜宴林（司法公正与同理心正义）

### 验证目标

| 指标 | 目标 | 计算方法 |
|------|------|---------|
| 命中率 | ≥ 70% | 3 个专家预期 pattern 中至少命中 2 个 |
| 误报率 | ≤ 10% | 2 个正样本 × 3 个 pattern = 6 次检查，最多 0 次误报 |

### 验证步骤

1. **实现 3 个 pattern 的检测 prompt**
2. **在 5 篇论文上运行检测**（使用单 pattern 模式）
3. **分析结果**：
   - 命中率：邵莉莉/杨清望/崔聪聪 是否正确触发对应 pattern
   - 误报率：蒋红珍/杜宴林 是否被误判
4. **如果达标**：扩展到全部 6 个 pattern + 13 篇论文
5. **如果不达标**：调整检测逻辑或重新设计 pattern

## 与 v2.51 Phase 0 的区别

| 维度 | v2.51 Phase 0（失败） | 新设计（推荐） |
|------|---------------------|--------------|
| Pattern 定义 | 抽象描述（"建议停留在方向性层面"） | 可观察指标（"规范性表述数量 vs 具体支撑数量"） |
| 检测方法 | 依赖 AI 主观判断 | 统计 + 比例计算 |
| Prompt 长度 | ~100 行（描述性） | ~50 行（指令性） |
| 输出格式 | triggered + severity + confidence | 统计数据 + 比例 + triggered |
| 验证规模 | 10 负样本 + 3 正样本（13 篇） | 3 负样本 + 2 正样本（5 篇，小规模） |
| 成功标准 | 命中率 ≥ 70%，误报率 ≤ 10% | 命中率 ≥ 70%，误报率 ≤ 10%（相同） |

## 风险与缓解

| 风险 | 概率 | 缓解 |
|------|------|------|
| AI 统计不准确（如漏数"应当"） | 中 | 提供明确的统计规则，要求输出详细列表 |
| 正样本也有高比例规范性表述 | 中 | 调整阈值（如 ratio < 0.3 改为 < 0.2） |
| 固定框架识别不准确 | 低 | 提供明确的框架模式列表 |
| 概念识别不准确（如普通词被误判为概念） | 中 | 要求只识别引号内的术语或明确的专有名词 |
