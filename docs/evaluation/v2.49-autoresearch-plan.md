# v2.49 Autoresearch 优化计划

## 目标

使用 autoresearch 自动迭代优化 v2.49 框架的负面模式检测规则，直到达成以下目标：
- 负样本平均分 < 75
- 正负样本差距 > 15
- 负样本致命缺陷识别率 > 70%

## Autoresearch 配置

```yaml
Goal: 优化 v2.49 框架的负面模式检测规则，使负样本平均分 < 75
Metric: 负样本平均分（越低越好）
Iterations: 5
```

## 迭代策略

### Iteration 1: 基线测试
- 使用当前 v2.49 框架测试 3 篇已知负样本
- 记录触发规则和得分
- 分析未触发规则的原因

### Iteration 2: 规则阈值调整
- 如果规则未触发，降低触发阈值
- 例如：concept_stacking 从"≥3个术语"降至"≥2个术语"
- 重新测试并验证

### Iteration 3: 检测方法强化
- 在 detection_method 中增加更明确的检测条件
- 添加量化指标（如"规范性表述占比 > 30%"）
- 重新测试并验证

### Iteration 4: Prompt 强化
- 在 prompt_template 中增加更强的负面模式检测指令
- 使用"必须检查"而非"建议检查"
- 重新测试并验证

### Iteration 5: 综合优化
- 综合前 4 次迭代的有效改进
- 生成最终优化版本
- 批量测试 10 篇负样本验证

## 验证标准

每次迭代后检查：
1. ✅ 至少 1 个新规则被触发
2. ✅ 负样本平均分下降 ≥ 5 分
3. ✅ 未误伤正样本（正样本得分保持 > 85）

## 输出

- 每次迭代的测试结果 JSON
- 规则触发统计
- 最终优化报告
