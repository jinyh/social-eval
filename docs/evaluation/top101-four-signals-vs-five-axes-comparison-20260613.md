## 1. 背景

项目在 Phase 2 全量评审后，先后对 Top101 候选池执行了两套"中国自主知识体系"相关评价：

1. **旧四信号**（`autonomous_knowledge_signals`，0-8 分）：中国问题中心性、中国实践解释尝试、外部理论转化动作、可复核概念或命题，每子项 0-2 分，总分 0-8。
2. **新五轴位置归属度**（v0.2 方案，0-10 分）：对象归属度、材料归属度、范畴自主度、解释目标归属度、体系映射度，每轴 0-2 分，总分 0-10。附带研究路径分类（7 条互斥路径）。

v0.2 方案（`docs/evaluation/autonomous-knowledge-system-position-assessment-v0.2.md`）明确批评旧四信号"区分度不足、与六维重叠、在 Top101 中饱和"。本文对两套方案在 Top101 上的实测表现做逐项对比。

### 8.2 跨学科推广性

- **前四轴可直接推广**：把"中国法学"替换为"中国 XX 学"即可，不需要预先存在学科手册
- **第五轴不可直接推广**：没有《手册》的学科无法判断"映射到哪个节点"
- **替代方案**：无手册的学科可只跑前四轴（0-8 分），或将体系映射度降级为"能否归入某个学科/子领域"

## 9. 核心矛盾与诊断

### 9.1 为什么五轴比四信号更饱和？

1. **Top101 本身就是高选择池**：能进入 Top101 的论文绝大多数是中国法核心议题，天然在对象/材料/目标上满分
2. **0-1-2 量尺只有三档**：对于"是否属于中国法"这种判断，绝大多数论文都是 2，模型很难给 1
3. **五轴中四轴不依赖《手册》**：只判断论文属性，而 Top101 论文的属性高度同质
4. **防饱和规则未严格执行**：v0.2 要求"仅使用中文法学术语不足以得 2"（针对范畴自主度），但模型在 86% 的论文中仍给了满分

### 9.2 设计改进 vs 区分度退化

| 维度 | 四信号 | 五轴 | 判断 |
|------|--------|------|------|
| 区分度 | 差（58% 满分） | **更差**（84% 满分） | 五轴在 Top101 上反而退化 |
| 理论独立性 | 与六维有重叠 | 更清晰分离 | 五轴设计更好 |
| 结构化程度 | 4 个二元信号 | 5 轴 + 路径 + 证据 | 五轴更丰富 |
| 手册依赖 | 无 | 仅体系映射度 | 五轴可解耦 |
| 瓶颈轴 | 可复核概念（100% 饱和） | 解释目标归属度（93% 饱和） | 都饱和 |
| 满分论文的五轴/四轴重合率 | — | 91.4% 同时满分 | 高度重合 |

**核心矛盾：五轴的理论设计比四信号更清晰、更独立，但在 Top101 这种高同质池里，两者的区分力都接近于零。五轴增加的复杂度（路径分类、证据引用、知识树匹配）在 84% 满分的场景下没有产生相应的区分收益。**

## 10. 可能的改进方向

### 10.1 短期（不改框架）

- **接受现实**：对于已筛选过的高质量论文，归属度评价的区分力天然有限；它的价值更多在于**画像和分层**而非精确排序
- **范畴自主度作为主区分轴**：在 Top50 选择中，对范畴自主度 <2 的论文做专家复核，这是唯一有效的区分信号

### 10.2 中期（调整量尺）

- **在范畴自主度和体系映射度上引入 0-1-2-3 四档量尺**：增加"核心且有可审计的证据链"档位
- **强化防饱和规则的执行**：对 CA=2 和 SM=2 的论文要求模型输出更具体的证据，否则降为 1
- **将体系映射度与知识树匹配结果硬绑定**：只有成功匹配到具体节点（非宽泛学科）的才给 2 分

### 10.3 长期（扩展评估范围）

- **全量 1920 篇评估**：在低分论文更多的全量池中，五轴的区分力会自然体现
- **与其他学科共享前四轴**：无《手册》的学科只跑前四轴，体系映射度留给后续专家或知识树建设完成后补入
- **将归属度评价与引用分析结合**：形成"归属度 × 引用影响 × 质量分"的三维画像

## 11. 全量 1920 篇方案推荐：采用四信号（改进版）

### 11.1 推荐方案

对 1920 篇全量评估，**推荐采用四信号方案（改进版）**，不推荐五轴。

### 11.2 推荐四信号的原因

**原因一：在 1920 全量池中，饱和问题会自然缓解。**

Top101 是高选择池（84% 满分），但 1920 篇包含大量比较法移植、域外制度介绍、一般法理、跨学科论文。四信号中真正"无用"的只有可复核概念（Top101 中 100% 满分），其余三子项在全量池中预计会有合理分布。

**原因二：五轴多出来的区分力不值得额外复杂度。**

Top101 实测数据已经证明：

- 五轴在 Top101 上 84% 满分，比四信号的 58% **更饱和**
- 唯一有区分力的轴是范畴自主度（86% 满分 vs 其他轴 90%+）
- 但为了这一个轴，要付出：路径分类 + 五轴评分 + 证据引用 + 知识树匹配，复杂度远高于四信号

**原因三：成本差距显著。**

| 方案 | 每篇 API 调用 | 1920 篇总计 |
|------|-------------|------------|
| 四信号（2 模型） | ~2 次 | ~3,840 次 |
| 五轴（2 模型 + 知识树检索） | ~2-4 次 + 检索 | ~3,840-7,680 次 + 检索 |

五轴的 prompt 更长（需嵌入路径定义、五轴锚点、防饱和规则、知识树节点），token 消耗也更高。

**原因四：四信号已经过实测验证。**

四信号在 Top101 上有 100 篇完整数据，行为可预测。五轴虽然也有 101 篇数据，但其体系映射度依赖知识树匹配——在 1920 篇全量跑时，知识树匹配的质量和覆盖率是未验证的风险。

### 11.3 必要改进：去掉"可复核概念"

四信号中**可复核概念（`verifiable_concept_or_thesis`）在 Top101 中 100% 满分**，在全量池中也极可能高度饱和（几乎所有法学论文都会提出某种可复核的概念或命题）。它已经成为常量，不贡献区分力。

**改进方案 A（推荐）：缩减为三信号（0-6 分）**

| 保留子项 | 说明 |
|---------|------|
| 中国问题中心性 (0-2) | 问题是否以中国法学为核心 |
| 中国实践解释 (0-2) | 是否尝试解释中国法实践 |
| 外部理论转化 (0-2) | 外部理论是否经过语境转化 |

| 去掉子项 | 原因 |
|---------|------|
| ~~可复核概念或命题~~ | 100% 饱和，不贡献区分力 |

**改进方案 B（备选）：替换为材料归属度**

将"可复核概念"替换为从五轴借来的**材料归属度**（核心材料是否来自中国法规范/判例/史料）。该子项在 Top101 中 90% 满分，但在全量池中预计有更多非中国材料的论文（如纯比较法、域外制度介绍），区分力更好。

### 11.4 五轴方案的保留价值

虽然不推荐五轴作为全量评估的主方案，但其设计仍有以下保留价值：

- **研究路径分类**（7 条路径）：可作为独立的论文画像标签，在 Top101/Top50 层面使用，无需全量运行
- **范畴自主度**的判断逻辑：可融入"外部理论转化"子项的评分锚点，增强其区分力
- **体系映射度 + 知识树匹配**：可在 Top50 专家审阅阶段作为辅助信息，不需要全量运行

### 11.5 综合对比

| 维度 | 四信号（改进版） | 五轴 |
|------|----------------|------|
| 实施成本 | 低（改一行配置） | 高（独立脚本 + 知识树） |
| API 成本 | ~3,840 次 | ~7,680+ 次 |
| 理论纯度 | 够用 | 更优雅 |
| 全量区分力 | 预计足够 | 略好但边际收益小 |
| 风险 | 低（已验证） | 知识树匹配覆盖率未验证 |
| 跨学科推广 | 容易 | 第五轴需要学科手册 |

### 11.6 结论

在全量池里，简单方案够用时不要用复杂方案。五轴的理论优雅在 Top101 上没有转化为区分收益，在 1920 篇上也不太可能。推荐采用改进版三信号（去掉可复核概念），将五轴的研究路径分类和范畴自主度判断逻辑作为补充资源，在 Top50/Top101 层面按需使用。
