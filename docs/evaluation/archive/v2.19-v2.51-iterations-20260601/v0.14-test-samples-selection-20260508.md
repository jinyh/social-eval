## 1. 样本选择原则

### 1.1 覆盖论文类型

根据项目已有测试结论，不同类型论文的多模型分歧程度不同：

| 论文类型 | 预期分歧 | 测试目的 |
|---------|---------|---------|
| 传统法学论证型 | 低 | 基线稳定性测试 |
| 理论建构型 | 高 | 测试高分歧场景 |
| 文化阐释型 | 高 | 测试高分歧场景 |
| 制度立法型 | 中 | 测试中等分歧场景 |

**目标分布**：
- 传统法学论证型：1-2 篇（基线）
- 理论建构型：2-3 篇（核心测试）
- 文化阐释型：1 篇（高分歧测试）
- 制度立法型：1 篇（中等分歧测试）

### 1.2 覆盖"中国自主知识体系"信号强度

v0.14 的核心变化是增加"中国自主知识体系"概念，需要测试中国模型在不同信号强度下的表现：

| 信号强度 | 定义 | 测试目的 |
|---------|------|---------|
| 强 | 明确涉及中国问题、中国实践解释、外部理论转化 | 测试中国模型优势 |
| 中 | 部分涉及中国问题或实践，但不是核心 | 测试边界情况 |
| 弱 | 主要是一般性法学理论，中国元素较少 | 测试中国模型是否过度偏向 |

**目标分布**：
- 信号强：3 篇
- 信号中：2-3 篇
- 信号弱：0-1 篇（可选）

### 1.3 避免样本污染

**污染定义**：样本之前参与过框架调参或规则优化

**污染风险**：
- `raw/calibration-regression/`：高污染风险（专门用于调参）
- `raw/holdout-test/`：中等污染风险（可能参与过 v0.8 测试）
- `raw/validation/`：低污染风险（最少被使用）

**选择策略**：
- 优先从 `raw/validation/` 选择
- 如果必须使用 `raw/holdout-test/`，标记为"已污染"
- 避免使用 `raw/calibration-regression/`

## 6. 样本标注建议

为了便于后续分析，建议对每篇样本进行人工标注：

### 6.1 标注维度

1. **论文类型**：传统法学论证型 / 理论建构型 / 文化阐释型 / 制度立法型 / 实证研究型
2. **中国自主知识体系信号强度**：强 / 中 / 弱
3. **核心议题**：简要描述论文的核心议题（1-2 句话）
4. **预期分歧程度**：低 / 中 / 高
5. **关键维度**：预期哪些维度可能出现高分歧

### 6.2 标注示例

```yaml
paper: raw/holdout-test/数字法学的理论表达_马长山.pdf
type: 理论建构型
signal: 强
core_issue: 数字法学的理论体系建构与中国数字治理实践
expected_divergence: 中高
critical_dimensions:
  - analytical_framework: 理论框架建构可能存在分歧
  - literature_insight: 新兴领域的文献覆盖判断可能不一致
```

### 6.3 标注用途

1. **测试前**：用于样本选择和测试设计
2. **测试中**：用于解释测试结果
3. **测试后**：用于验证假设和生成报告
