## 🚀 快速开始

### 方式 1：使用快速启动脚本（推荐）

```bash
# 运行交互式菜单
./scripts/run_v0.14_test.sh
```

菜单选项：
1. **小规模测试**（2 篇）：验证脚本和配置是否正常
2. **完整测试**（6 篇）：全面评估三中国模型的稳定性
3. **单篇测试**：自定义测试单篇论文
4. **退出**

### 方式 2：直接使用 Python 脚本

#### 单篇测试

```bash
# 测试单篇论文
python scripts/run_v0.14_multi_model_test.py \
    --paper raw/holdout-test/数字法学的理论表达_马长山.pdf \
    --output results/test-single.json

# 禁用 GPT 复核
python scripts/run_v0.14_multi_model_test.py \
    --paper raw/holdout-test/数字法学的理论表达_马长山.pdf \
    --no-gpt-review \
    --output results/test-single-no-gpt.json
```

#### 批量测试

```bash
# 批量测试 6 篇预定义样本
python scripts/run_v0.14_multi_model_test.py \
    --batch \
    --output-dir results/v0.14-batch-test

# 禁用 GPT 复核
python scripts/run_v0.14_multi_model_test.py \
    --batch \
    --no-gpt-review \
    --output-dir results/v0.14-batch-test-no-gpt
```

## 📈 测试指标

### 核心指标

1. **整体稳定性**
   - 三模型平均 std（期望 < 8 分）
   - 高置信度比例（std ≤ 5 分的论文占比，期望 > 50%）

2. **维度级稳定性**
   - 六个维度各自的平均 std
   - 识别哪些维度分歧最大

3. **"中国自主知识体系"信号识别一致性**
   - 三模型对新增概念的理解是否一致

4. **论文类型与分歧的关系**
   - 不同类型论文的平均 std

5. **GPT 复核介入效果**
   - GPT 复核模型触发率
   - GPT 复核模型是否能"打破僵局"

### 成功标准

**方案 A：三中国模型策略可行**
- ✅ 三模型平均 std < 8 分
- ✅ 高置信度比例 > 50%
- ✅ 关键分歧比例 < 20%

**方案 B：三中国模型 + GPT 复核策略可行**
- ✅ 三模型平均 std 在 8-12 分之间
- ✅ GPT 复核模型能在 > 60% 的分歧案例中"打破僵局"
- ✅ GPT 复核模型触发率 < 30%（成本可控）

**方案 C：需要人工复核机制**
- ❌ 三模型平均 std > 12 分
- ❌ GPT 复核模型也无法降低 std

## 🔍 故障排查

### 问题 1：API Key 未设置

**错误信息**：`KeyError: 'DASHSCOPE_API_KEY'`

**解决方法**：
```bash
# 在 .env 文件中添加
DASHSCOPE_API_KEY=your_key

# 或临时设置
export DASHSCOPE_API_KEY=your_key
```

### 问题 2：模型调用失败

**错误信息**：`Provider error: ...`

**解决方法**：
1. 检查 API Key 是否正确
2. 检查网络连接
3. 检查 API 配额是否用尽
4. 查看 `src/evaluation/providers/` 中的 provider 实现

### 问题 3：PDF 解析失败

**错误信息**：`Failed to process file: ...`

**解决方法**：
1. 检查 PDF 文件是否损坏
2. 检查是否是扫描版 PDF（需要 OCR）
3. 尝试重新下载或转换 PDF

### 问题 4：内存不足

**错误信息**：`MemoryError` 或进程被杀

**解决方法**：
1. 减少并发数量（修改脚本中的 `asyncio.gather`）
2. 分批测试（先测试 2-3 篇）
3. 增加系统内存
